# 직사각형 재하와 응력 중첩

기존 `stress-spread` 실험의 `rectangle` 질문이다. 원형 등분포·점하중 질문은 유지한다. 질문 안에서 한 개/두 개 재하면을 선택하며, 단순 출력 전환을 별도 질문으로 만들지 않는다.

## 학습 범위

- B, L, 추가 재하압 q₁, 관찰깊이 z와 관찰위치 x를 함께 바꾼다. q₁을 고정한 치수 변경은 총하중 Q₁=q₁BL도 바꾼다.
- 두 재하면은 같은 B×L이고 첫 중심은 (0,0), 두 번째는 (s,0)이다. 첫 위치는 모드 변경 때 이동하지 않는다. q₂=(q₂/q₁)q₁.
- s≥B의 서로 겹치지 않는 면을 사용한다. 재하면이 분리되어 있어도 지중의 응력은 중첩된다. 겹치는 입력을 조용히 이동/보정하지 않는다.
- 관찰점은 y=0 중심선을 따라 이동한다. 평면, 실제 x–z 단면의 응력장, 현재 x의 깊이별 응력곡선을 표시한다. 두 개 모드는 각 기여와 합계를 함께 표시한다.
- 저장한 기준의 평면 치수·단면 재하폭·관찰점과 깊이별 합계곡선을 실제로 표시한다. 다른 재하면 개수도 비교할 수 있다.

이는 균질·등방 선형탄성 반무한체에 작용하는 **유연한 지표 등분포 재하의 수직응력 증가**이다. 지반 자중, 간극수압, 유효응력 변환, 층별 강성, 비선형 변형, 지지력, 침하, 기초 강성에 따른 접지압 재분배를 계산하지 않는다. 근입기초의 굴착·하중 장부나 순증분 재하압은 별도 판단이 필요하다. 그림은 유한한 직사각형의 3D 해를 y=0에서 자른 것이며 2D 띠하중 해가 아니다.

## 공식과 출처

1. [USACE EM 1110-1-1905 (2025)](https://publibrary.sec.usace.army.mil/api/download?filename=EM+1110-1-1905_Geotechincal+Design+of+Shallow+Foundations+on+Soils_2025+07+22+-+Final.pdf&id=54658636-77d2-48df-f26b-5295a01899a7&preview=true), §6–6e(2), pp.131–132, Figure 6–5: 직사각형의 분할·가감으로 재하면 안과 밖의 관찰점에 대한 영향을 합산하는 원리. §6–7a, p.133와 Figure 6–8, p.136: Boussinesq 가정과 직사각형 모서리 영향계수. 이 문서의 현장 설계 권고나 허용성을 본 실험의 적합 판정으로 사용하지 않는다.
2. [FHWA-HRT-15-080 (2016), §3.5](https://www.fhwa.dot.gov/publications/research/infrastructure/structures/bridge/15080/003.cfm): 점하중 탄성해를 직사각형 등 면적재하에 적분하는 원리와 균질·등방·반무한체 가정. 보강토와 같은 조건에서 가정이 성립하지 않을 수 있음을 구분한다.

원출처의 점하중 커널을 직사각형에 직접 적분한 폐형식을 사용한다. 문서의 도표를 디지타이즈하거나 2:1 분산식으로 대체한 값이 아니다.

```text
Δσz = ∫A 3q z³ / [2π(ρ²+z²)^(5/2)] dA

z>0, R=√(u²+v²+z²):
F(u,v,z) = {atan[uv/(zR)] + (uvz/R)[1/(u²+z²)+1/(v²+z²)]}/(2π)
I = F(u2,v2,z) - F(u1,v2,z) - F(u2,v1,z) + F(u1,v1,z)
Δσz = q I

u1 = centerX − B/2 − x; u2 = centerX + B/2 − x
v1 = centerY − L/2 − y; v2 = centerY + L/2 − y

Δσz,total = Δσz,1 + Δσz,2
```

u, v는 부호 있는 상대좌표다. `atan2(uv,zR)`의 두 번째 인수는 z>0에서 양수이므로 식의 atan과 같은 올바른 사분면을 유지한다. 곱의 overflow를 줄이기 위해 각 모서리 길이를 공통 척도로 나누어 계산한다. z=0은 적분식에 작은 양수를 넣는 대신 명시적으로 극한을 반환한다. 내부 q, 변 q/2, 모서리 q/4, 외부 0이며 두 면이 맞닿은 변에서는 두 q/2를 합산한다.

영향계수의 미소 음수/1 초과가 32×machine epsilon 이내인 경우에만 물리적 경계로 반올림한다. `roundoffBound`는 이 경계 처리의 수치 허용치이며 모든 극단 치수비에 대한 엄밀 오차보증이 아니다. 표현 불가, 붕괴한 모서리 좌표, 비유한 값은 실패로 반환한다. UI 지원 치수·관찰 범위는 아래와 같이 제한된다.

## 수치 API와 단위

`RectangularStress.rectangle({width,length,pressure,x,y,depth,centerX,centerY})`

일반 관찰점의 한 직사각형 해. 기본값 B=2 m, L=3 m, q=100 kPa, (x,y,z)=(0,0,3) m, 중심=(0,0). 반환: `valid`, `influence`, `stress` kPa, `area` m², `load` kN, 표면 극한 여부·위치와 오차 경계 처리 허용치. 물리조건 B,L>0, q,z≥0이며 문자열 강제변환을 하지 않는다.

`RectangularStress.field({width,length,pressure,depth,x,mode,spacing,ratio})`

UI용 검증과 두 재하면 합산, 단면 격자, 깊이곡선을 반환한다. 기본 mode=`single`, spacing=4 m, ratio=1. double일 때만 s와 ratio를 검증한다. 반환의 `parts[]`는 각 응력 기여, `influences[]`는 각 I, `stress`는 합계이다. `patches[]`, `cells[]`, `profile[]`도 반환한다.

| 입력 | 범위 | descriptor 필드 |
|---|---:|---|
| B | 0.5–6 m | rectWidth |
| L | 0.5–10 m | rectLength |
| q₁ | 0–600 kPa | rectPressure |
| z | 0–12 m | depth, 기존 질문과 공유 |
| x | −4–16 m | rectX |
| 모드 | single / double | rectMode |
| 중심간격 s | B–12 m, 두 개에서만 | rectSpacing |
| q₂/q₁ | 0–2, 두 개에서만 | rectRatio |

원형 질문의 Q/q와 직사각형의 q₁은 별도 입력이다. `activeFields`로 현재 질문에서 사용하지 않는 입력의 오류를 차단하지 않는다.

## 독립 검증

`tests/rectangular-stress.test.mjs` 12개 검사:

- B=L=z=1인 모서리의 손계산 I=1/12+1/(2π√3). B=L=2, z=1의 중심은 그 4배 → q=100에서 70.0885930281 kPa.
- 중심/변/외부/비대칭 길이/이동한 재하의 5조건을 독립 2D Simpson 점하중 면적적분으로 검사. 80×80→160×160 분할 수렴도 확인한다.
- 표면 내부/변/각/외부 및 z→0 극한, 대칭·평행이동·B/L 회전·길이비 상사·압력 선형성.
- 원거리에서 같은 Q의 점하중으로 수렴. 원형 영역을 100→3200개의 유한 직사각형 띠로 근사하여 기존 원형의 별도 극좌표 적분과 비교한다.
- 두 응력의 합산, q₂=0/2배, 첫 위치 보존, 맞닿은 두 면과 하나의 큰 면의 동등성, s<B 거부, inactive 오류 격리.
- 지원 범위의 극단 조합 48개에서 관찰점·전체 격자·깊이곡선의 유한성, 비음수 및 물리적 상한.
- descriptor의 활성 입력, 기준 형상/곡선 표시, 이론식 수치대입, 현재 원형/점하중 질문 격리.

대표값: B=2 m, L=3 m, q₁=100 kPa, x=0, z=3 m에서 단일 Δσz=24.4942129605 kPa. s=4 m, q₂/q₁=1인 두 번째를 추가하면 기여 2.5647915245 kPa, 합계 27.0590044850 kPa. Q는 각각 600 kN이고 합계 1200 kN이다.

그림의 색은 0–100 kPa 고정 척도이며 초과는 같은 진한색이다. 0.5 m 셀 중심을 표시하므로 표면 근처의 세밀한 분포가 색상만으로 모두 표현되지는 않는다. 관찰점은 직접 해석식으로 계산하며 깊이곡선은 표면 가까이에 더 촘촘한 표본을 배치한다. x–z 단면과 평면은 각각 두 축의 길이 척도가 같고, 오른쪽 깊이곡선은 독립 응력–깊이 축이다.

화면 검증: 390·768·1440 px에서 각 8조건(직사각형 단일·두 개, 최대/최소·무재하·표면 인접경계·얕은 관찰, 기존 원형·점하중)을 렌더한 24검사 통과. 수평 넘침, SVG 문자 잘림, 비유한 좌표, 슬라이더와 숫자 불일치, 브라우저 오류가 없었으며 단일·두 개의 데스크톱 및 모바일 이미지를 직접 확인했다.
