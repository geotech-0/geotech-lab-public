# 흙막이 시공과정

기존 `토압·굴착·사면 → 굴착 순서와 앵커` 자리를 확장한 교육용 실험이다. 새 실험은 `modelVersion: 2`를 사용한다. 이전 저장 파일의 11개 입력과 선형 해석은 그대로 유지하며, 새 실험의 기본값을 옛 입력에 병합하지 않는다.

## 화면과 입력

- 굴착 구간은 H=0에서, 되메움 구간은 최대 굴착깊이에서 시작한다. 되메움 바는 채운 높이가 증가하는 방향으로 움직인다.
- 지보 종류는 하나를 선택하면 모든 단에 함께 적용한다. 조절할 단 선택은 깊이·강성·개별 시공 여유 등에만 사용하며 대체 슬래브는 공통 종류 변경 대상에서 제외한다. 이전 혼합 저장 자료는 원본을 유지해 열고, 공통 종류를 선택하는 순간 통일한다.
- 스트럿·코너스트럿의 수직 경사는 0°다. 이 종류에서 경사 지보로 변경하면 어스앵커·네일·락볼트는 15°, 레이커는 35°의 편집 가능한 예제 각도를 적용한다. 해석 입력과 단면 그림에 같은 값이 반영된다.
- 단면과 순수평압력·수평변위·전단력·모멘트를 같은 깊이 축으로 표시한다. 토압 패널은 양쪽 압력과 차이를 구분한다. H=0에서 양측 초기압이 있어도 순압과 변위는 0일 수 있다.
- 지보 위치 z와 설치 작업면 H는 별개다. 공통 작업여유 0.5 m를 예제로 사용하고, 단별 설치·해체 예외를 지정할 수 있다. 기본 해체깊이는 해당 단의 유효 설치깊이를 따른다.
- 설치 전 / 설치 후·긴장 전 / 긴장 후를 같은 깊이에서 구분한다. 같은 깊이에 슬래브 연결과 임시 지보 해체가 있으면 대체 지지를 먼저 연결한다.
- 원지반과 되메움토는 각각 한 종류다. 원지반은 배면과 굴착측의 남은 근입 지반에 적용한다. 되메움토는 원지반 값을 복사한 뒤 독립적으로 편집할 수 있다.
- 기본 토질 입력은 γ·γsat·c′·φ′·kh·K0다. N값을 추가 곱하거나 강성에 중복 반영하지 않는다. 직접 kh를 입력하므로 E 입력을 중복 요구하지 않는다. K0 자동값은 정규압밀 토사의 Jaky 가정이다.
- 이 모델의 강도 입력은 배수 유효응력 체계다. 단기 비배수 점토를 c′·φ′에 임의 대입한 해석으로 해석하지 않는다.
- 양측 수위·상재하중·EI·근입깊이를 별도로 입력한다. 되메움 중 굴착측 수위는 되메움 진행률에 따라 초기 수위에서 완료 목표수위까지 선형 복구하는 지정 경로다. 침투해석에서 구한 수위가 아니다.
- 표시 깊이 0.01 m는 해석 정확도가 아니다. 기본 벽체 요소 길이 0.5 m, 공정 증분 0.25 m를 사용하며 설치·해체 위치를 정확히 포함한다.

## 해석 모델

벽체는 Euler–Bernoulli 보 요소이고, 지반은 양측 독립 탄소성 반력 스프링이다. 단위 폭 EI에 실제 벽체 스트립의 부담 폭을 곱한다. 토압과 수압은 별도 계산한다.

유효 수직응력과 Rankine의 주동·수동 한계 사이에서 지반 저항을 계산한다. γ·c′·φ′는 자중과 저항 한계를, kh는 탄성구간의 압력–변위 기울기를 정한다. kh의 단위는 kN/m³이고 E의 단위 kPa와 다르다. 일정 재하·제하 강성을 사용하는 단순화이며, 소변형 강성 저하·압밀 시간·침투·동적 충격을 해석하지 않는다.

지반 상태는 수렴한 공정에서만 갱신한다. 이전 압력·변위·소성 상태와 무인장 접촉 상태를 다음 공정으로 넘긴다. 되메움은 채워지는 시점의 벽체 위치를 기준으로 새로 활성화한다. 이미 발생한 변위에 새 되메움 kh를 곱해 가짜 반력을 만들지 않는다. 채움의 자중은 아래 남은 원지반의 유효 상재압에도 반영한다.

잠금력은 별도의 힘 제어 평형으로 도입한 뒤 수렴 위치를 지보 기준으로 저장한다. 따라서 긴장 직후의 축력은 입력한 유효 잠금력과 일치한다. 평면 프레임의 경우 띠장에 이미 전달된 힘도 잠금 상태에 보존한다.

지반·지보 접선강성이 현재 하중을 지탱하지 못하거나 수치 반복이 수렴하지 않으면 유효 결과로 처리하지 않는다. 비수렴을 붕괴 안전율이나 실제 파괴 판정으로 바꾸지 않는다.

### 지보별 전달 모델

| 종류 | 구현한 힘 전달 |
|---|---|
| 어스앵커 | 경사 투영, 축강성·정착부 직렬 강성, 긴장·잠금·긴장 해제, 인장 전용 및 축력 한계 |
| 네일 | 무긴장을 기본으로 하는 벽 연결형 등가 축·부착 보강재, 변형에 따른 저항 동원과 기본 잔존 |
| 락볼트 | 긴장 여부를 입력하는 벽 연결형 등가 축·정착 보강재, 기본 잔존 |
| 스트럿 | 수평 압축 부재, 실제 평면 길이에 따른 EA/L와 본수·간격; 단일 벽 모드에서는 맞은편 벽의 대칭 변위 가정 |
| 코너스트럿 | 선택한 코너별 실제 양단 접점과 길이, 수평 띠장 휨과 인접 벽체 스트립의 변위 결합 |
| 레이커 | 경사 압축 부재와 받침 강성의 직렬 연결, 수평 성분 전달 |
| 대체 슬래브 | 되메움 중 지정 깊이에서 활성화하는 별도 압축 지지, 임시 지보 해체 후 잔존 |

축강성과 초기력은 1본 기준이고 평면 간격·스트립 폭으로 벽체에 전달한다. 축력 상한은 등가 저항 한계이며 부재의 좌굴·단면 설계나 정착부 설계 검토를 대신하지 않는다. 지보 축력 한계의 반복하중 손상·영구 정착부 미끄러짐을 별도로 예측하지 않는다.

네일·락볼트라는 명칭만으로 곡선을 다르게 만들지 않는다. 같은 지반·축/부착 강성·초기력·연결조건이면 같은 등가 벽체 결과가 나올 수 있다. 독립 보강사면, 절리 블록의 회전·활동 또는 벽체 없는 암반에 가상 벽체 M/V를 부여하지 않는다. 숏크리트는 선택 대상에서 제외했다.

### 평면 결합

코너 지보가 있는 모형은 네 벽에 각각 기본 3개 수직 스트립을 두고, 지보 각 단의 수평 띠장을 별도 보로 모델링한다. 코너 접점과 스트립 접점에 절점을 만들며, 실제 부재 방향으로 축강성을 투영한다. 띠장 내부 자유도를 정적 축약하여 벽체 스트립 사이의 결합 강성을 얻는다. 압축 전용·축력 한계를 만족하는 부재 상태를 반복해 구한다.

관찰 위치는 선택한 벽의 가장 가까운 계산 스트립이다. 화면에 실제 계산 위치를 표시한다. 이 방법은 띠장–지보–벽체 스트립의 구조 모델이며 3차원 지반 연속체, 수평 지반 아칭, 연속벽 판의 모든 효과를 구현한 것은 아니다. 스트럿과 코너스트럿 양단은 같은 높이인 수평 부재로 제한한다.

## 이력·비교·저장

- 역방향 바 이동은 이미 정의한 시공 이력을 조회한다. 실제 굴착 공정을 거꾸로 시행하지 않는다.
- 물성을 바꾸면 다른 시나리오로 처음부터 재계산한다. 이전 물성의 소성 상태를 새 물성에 그대로 붙이지 않는다.
- 계산 캐시는 고정 증분과 사건이 완료된 상태만 재사용한다. 중간 깊이 관찰이 다음 조회의 시공 경로에 섞이지 않는다. 캐시에는 크기 제한이 있다.
- 기준안은 현재와 같은 공정·깊이·관찰 위치에서 다시 계산해 겹친다. 기준안이 해당 깊이에 도달하지 못하면 그 이유를 표시한다.
- 현재 형상 모드는 지정 주동 외압과 탄성 반력·무변형 지보 기준으로 독립 계산한다. 시공 이력 모드와의 차이에는 하중·재료모형·기준상태 차이가 포함된다. 모든 차이를 누적변형 효과라고 부르지 않는다.
- 총결과, 직전 계산 증분 변화, 현재까지의 포락선을 구분한다. 현재 형상 모드에는 시공 이력의 증분/포락선을 적용하지 않는다.
- 새 실험 파일은 v5다. v1–4, 학습기록과 계산서의 기존 형식은 계속 읽는다. 원본 저장을 읽지 못한 경우 자동 저장으로 덮어쓰지 않으며, 검증된 전체 작업공간 복원 뒤에 저장을 재개한다.

## 참고 및 검증 범위

공식 프로그램 문서를 모델 구분과 입력 의미의 참고자료로 사용했다. 해당 프로그램과 동일한 내부 구성식이나 검증된 수치 일치를 주장하지 않는다.

- [GEOXD 지반 정의](https://manual.midasuser.com/KR/GeoXD/Analysis/latest/model/soil-definition.html): 굴착부 되메움 kh 스프링과 두 벽 사이 뒤채움 E/gap 모델 구분.
- [GEOXD 시공단계](https://manual.midasuser.com/KR/GeoXD/Analysis/latest/model/construction-stage.html): 설치 작업면·지보 활성화·되메움·해체.
- [DeepEX 비선형 해석](https://www.deepexcavation.com/post/deep-excavations-non-linear-analysis-method): 독립 지반 스프링과 단계별 상태 갱신.
- [FHWA Soil Nail Walls](https://highways.fhwa.dot.gov/sites/fhwa.dot.gov/files/FHWA-NHI-14-007.pdf), [암반 내부 보강](https://www.fhwa.dot.gov/clas/ctip/context_sensitive_rock_slope_design/ch_5_2.aspx): 네일과 락볼트의 역할·긴장 방식 구분.

이 구현은 독립 보 해석해, 전체 힘·모멘트 평형, 지반 구성법칙, 지보 잠금, 설치·해체 사건, 캐시 이력 독립성, 메시·증분 수렴, 평면 프레임 힘 전달·접선강성을 테스트한다. SUNEX·GEOXD·DeepEX 실행 결과와 동일 입력의 정량 대조는 아직 수행하지 않았다. 로컬 구현·브라우저 검증과 실제 배포 상태를 구분한다.

재현 가능한 입력·수치 결과는 [단계굴착 예제](examples.md#1-excavation-installation-lock-off-and-backfill)에, 검사 범위와 재실행 방법은 [검증 안내](validation.md)에 정리했다.
