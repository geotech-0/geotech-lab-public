# 압밀시험점에서 구간 정수 읽기

기존 `compression` 실험의 `reading` 질문이다. 응력이력 질문에서 Cc·Cr를 넣어 곡선을 만드는 것과 반대 방향으로, 지정된 두 점의 차이에서 정수를 읽는다. 메뉴는 추가하지 않는다.

두 고정 계열은 자체 지정한 교육용 자료이며 실측 자료가 아니다.

- 재하: σ′=[50,100,200,400,800] kPa, e=[.900,.885,.870,.780,.690]. 예제에서 50~200은 재압축, 200~800은 처녀압축으로 지정했다.
- 제하: σ′=[800,400,200,100,50] kPa, e=[.690,.705,.720,.735,.750]. 점 번호는 시간 순서다.

경로와 첫 점·끝 점을 바꾸어 다음을 계산한다.

```
Csec = (e1−e2)/log10(σ′2/σ′1)
Δε = (e1−e2)/(1+e1)
mv = Δε/(σ′2−σ′1)
M = 1/mv
```

변형률은 첫 점의 시료 높이 기준이다. 제하의 Δσ′·Δε는 모두 음수, mv·M은 양수다. M은 1D 구속계수이며 Young 계수 E가 아니다. 현재 기본값 200→800 kPa에서는 Csec≈0.298974, mv≈0.000160428/kPa, M≈6.23333 MPa다. 같은 Cc 구간도 응력 수준에 따라 mv가 다르다.

재압축·처녀압축을 함께 가로지르면 `구간 할선 Csec`로만 표기하며 어느 한 지수로 자동 채택하지 않는다. 제하에서는 Cs를 사용하고 Cr와 항상 동일하다고 일반화하지 않는다. 두 점으로 선행압밀응력을 자동 판정하지 않는다. 실제 시험의 회귀·시료 교란·재하속도·시간자료의 cv 판정·현장 정수 채택은 이 실험에서 수행하지 않는다.

직접 근거:
- [FHWA GEC 5 (2002), §5.4.2.2, p.126](https://www.fhwa.dot.gov/engineering/geotech/pubs/010549.pdf): 압축지수, Δε=Δe/(1+e0), 구속계수 D=Δσ′/Δε=1/mv 정의. 위 구현은 이를 선택한 두 점 사이 유한차이로 사용한다.
- [FHWA NHI-16-072, §6.7](https://www.fhwa.dot.gov/engineering/geotech/pubs/nhi16072.pdf): 실제 측정 e–logσ′ 경로의 해당 구간에서 Cc·Cr를 평가하는 절차. 선택 구간의 중요성과 자동 판정의 범위를 구별한다.

`tests/oedometer-reading.test.mjs`는 독립 손계산, 같은 Cc/다른 mv, 전이 구간 오표기 방지, 제하 부호, 모든 선택쌍의 부피·응력 관계, 잘못된 점 선택 및 비활성 응력이력 입력 격리를 확인한다.
