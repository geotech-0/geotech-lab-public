# 점토의 재성형과 침수 전후 체적변화

계획 영역 03·12·25의 일부를 `soil-response` 한 실험의 두 질문으로 제공한다. 입력값은 모두 **교육용으로 지정한 시험값**이다. 함수비·LI·광물 이름으로 강도, 체적변화 또는 팽윤압을 생성하는 구성모형이 아니다.

| 질문 | 주요 입력 | 계산·시각화 |
|---|---|---|
| 재성형과 강도 | 불교란 qu,i, 같은 함수비의 완전 재성형 qu,r | 각 su=qu/2, St, 남은 강도 비율, 동일 척도 Mohr 파괴 전응력원 |
| 침수와 체적변화 | 침수 직전 eb, 같은 수직응력의 침수 후 ea, 대표층 두께 H, 시험 σv | 압축 변형률, 대표층 높이 변화, 같은 고체량의 높이 비교, 동일 시험응력의 두 e 관측점 |

첫 질문에는 필요한 독립 강도값 2개만 놓았다. 함수비를 추가로 조작한다고 St가 자동 예측되는 인상을 주지 않는다. 두 번째 질문에는 4개 슬라이더를 함께 노출하며 σv는 두 관측값의 시험조건임을 설명한다.

## API

순수 계산 모듈 `src/soil-response.mjs`는 namespace `SoilResponse`를 제공한다.

- `sensitivity({intactQu,remoldedQu})`: 두 su·강도비·전응력 Mohr 원.
- `wetting({beforeVoid,afterVoid,thickness,verticalStress})`: 지정 시험변형률과 대표층의 1D 높이 변화.
- `experiment(data,question)`: `remolding`/`wetting` 질문별 활성 계산.

응력은 kPa, 길이는 m, 간극비·변형률·강도비는 무차원이다. 반환 `compressionStrain`은 소수 비율이며 화면에서 100을 곱해 %로 표시한다. `heightChange`는 침수 후 높이−침수 전 높이로, 팽창이면 양수다. `settlement=-heightChange`로 압축 침하는 양수다. 화면 결과는 방향을 ‘침하’ 또는 ‘융기’로 표기하고 크기를 m로 표시한다.

`src/labs/soil-response-labs.js`의 `SoilResponseLabs`는 `navGroup:'properties'`이며, `activeFields`가 다른 질문의 미완성 입력을 일반 UI 범위검사와 엔진 모두에서 제외한다. 현재와 기준의 실제 그림이 함께 그려진 때만 `comparisonPlot:true`다.

## 같은 함수비에서의 재성형 비교

```text
UC 파괴 시 σ3=0, σ1=qu
Mohr 원 중심 = qu/2, 반지름 = qu/2
포화·비배수·φu=0 해석에서 su=qu/2
St = su,i/su,r = qu,i/qu,r
재성형 후 남은 강도 비율 = qu,r/qu,i
```

기본 지정값 qu,i=120 kPa, qu,r=20 kPa이면 su,i=60 kPa, su,r=10 kPa, St=6이고 재성형 후 강도는 1/6이다. 두 qu가 같은 배율로 커지면 절대강도는 커지지만 St는 변하지 않는다. 원의 지름인 qu와 반지름인 su를 구별한다. 그림의 가로·세로축은 같은 응력척도다.

적용 조건은 같은 흙·같은 함수비, 불교란과 완전 재성형 시료의 비교, 포화·비배수 일축압축 및 φu=0 전응력 해석이다. 입력 qu는 파괴 시 단면적 보정을 적용한 축응력으로 지정한다. 하중·축변형률 기록이나 단면적 보정 과정은 생성하지 않는다.

매우 연약한 점토나 균열이 심한 시료처럼 무구속 상태에서 자립하지 못하는 흙에는 UC 해석을 일반화할 수 없다. 입상토와 불포화토에도 같은 조건으로 적용하지 않는다. 수압을 측정한 값이 없으므로 유효응력원·c′·φ′는 표시하지 않는다. LI 또는 함수비만으로 St를 산정하거나 예민비 등급·지질·현장 파괴 가능성을 자동 판정하지 않는다.

qu,r=0 또는 검출한계 이하를 임의의 큰 예민비로 바꾸지 않는다. 엔진은 0 이하 입력을 오류로 처리하며, 실제 검출한계 문제는 정량화 불가로 해석해야 한다. qu,r>qu,i이면 입력값을 교환하거나 비율을 1로 제한하지 않고 St<1 및 비교 조건 확인 문구를 표시한다.

근거는 [FHWA NHI-16-072 §7.4.2, Eq.(7.7), Fig.7-22](https://www.fhwa.dot.gov/engineering/geotech/pubs/nhi16072.pdf)의 UC 시험 조건과 전응력 해석, 같은 문서 §5.11, Eq.(5.14)의 동일 함수비 예민비 정의다.

## 같은 수직응력에서 관측한 침수 반응

횡변형이 없고 고체량·단면적이 일정하면 고체 부피에 대응하는 높이 `Hs=H/(1+e)`가 일정하다.

```text
H/(1+eb) = Ha/(1+ea)
εc = (eb−ea)/(1+eb)                 압축 (+), 팽창 (−)
Ha = H(1+ea)/(1+eb)
ΔH = Ha−H = −εcH                  팽창 (+), 압축 (−)
```

**eb와 H는 지정 수직응력까지 재하한 뒤, 침수 직전 상태**다. 침수 전 재하 과정의 압축량은 포함하지 않는다. 예를 들어 eb=0.9, ea=0.805라면 εc=5%다. 같은 변화는 시험 높이가 20 mm에서 19 mm가 된 관측과 일치한다. 이를 대표층 H=2 m 전체에 균일하게 적용하는 예제에서는 침하 0.1 m, 침수 후 두께 1.9 m다.

ea>eb이면 팽창이며 εc<0이다. 같은 입력 간극비 쌍에서 H를 2배로 하면 변형률은 같고 높이 변화만 2배가 된다. 시험 σv를 바꾸는 것은 관측값의 조건을 바꾸는 것이다. 입력 eb·ea를 그대로 둔 채 σv만 바꾸어도 결과 변형률은 달라지지 않는다. 다른 응력에서의 반응은 그 조건의 시험값이 별도로 필요하다.

왼쪽의 고체·간극 블록은 동일 고체량에 대한 부피 관계다. 실제 입자배열이나 물·공기 비율이 아니다. 오른쪽은 같은 수직응력의 두 관측점이며, 연결선은 차이를 보여줄 뿐 시간경로나 e–σ 구성곡선이 아니다. 시험응력은 외부 수직 재하조건이며, 불포화 상태의 흡수력·유효응력을 추정하지 않는다.

대표층 전체에 같은 시험변형률을 적용하는 것은 명시한 1D 환산이다. 실제 현장의 깊이별 응력, 침수 범위, 물의 공급속도, 시료 대표성, 다층 영향까지 해석한 침하예측이 아니다. 또한 자연상태 간극비·높이를 분모로 삼는 특정 표준의 붕괴지수나 등급과 자동으로 동일시하지 않는다.

같은 응력에서 침수시킨 관측의 해석은 [FHWA NHI-16-072 §5.2.3](https://www.fhwa.dot.gov/engineering/geotech/pubs/nhi16072.pdf), 간극비 변화와 층 두께의 관계는 [USACE EM 1110-1-1904, Eq.(5-4a), p.5-6](https://www.publications.usace.army.mil/Portals/76/Publications/EngineerManuals/EM_1110-1-1904.pdf)를 확인했다. 표준 시험의 최신 판본 수행 절차나 지수 등급을 구현했다고 주장하지 않는다.

## 팽윤량·자유팽윤·팽윤압의 구별

주어진 하중 아래 높이가 늘어난 양과, 높이 증가를 막기 위해 필요한 압력은 다른 측정량이다. 정변형 팽윤압 시험의 압력 기록 없이 eb·ea 두 개로 팽윤압을 역산하지 않는다. 팽윤 후 원래 높이로 되누르는 재재하 압력도 최초부터 변형을 막은 시험과 하중경로가 다를 수 있다.

σv=0을 지정해도 현재 모형은 횡방향이 구속된 1D 무재하 관측이다. 분쇄·건조한 흙을 물에 넣어 측정하는 자유팽윤지수와 같은 시험이 아니다. 이러한 시험조건 구별은 [FHWA NHI-16-072 §§5.3.3–5.3.4](https://www.fhwa.dot.gov/engineering/geotech/pubs/nhi16072.pdf) 및 [USACE EM 1110-1-1904 §5](https://www.publications.usace.army.mil/Portals/76/Publications/EngineerManuals/EM_1110-1-1904.pdf)를 따른다.

## 검증

`tests/soil-response.test.mjs`의 24개 검증은 다음을 포함한다.

- UC 손계산, 원의 응력축 양 끝·반지름·수평 강도선의 접점 기하.
- 공통 강도배율 불변성, 재성형 강도 변화, St=1 및 St<1 처리.
- 0 강도·문자열·비유한값·계산 범위 초과 거부.
- 별도 시험높이 20→19 mm 손계산과 간극비식의 일치, 팽창·무변형·압축 부호.
- 고체량 보존, 층두께 배율, 관측 쌍을 역으로 적용한 높이 복원.
- 시험응력만 바뀌었을 때 가짜 구성반응이 생기지 않음, 분모의 기준 상태 확인.
- 0 간극비·0 시험응력의 수학적 경계, 불가능한 부호·비유한 입력 거부.
- 2개 질문의 현재/기준 SVG 유한성, 입력 수 2/4개, 비활성 입력 검사 격리, 슬라이더 끝점.

화면 변경 시에는 재성형과 침수 질문의 현재/기준 표시, 비활성 입력 격리, 잘못된 입력의 오류·복구와 좁은 화면을 확인한다.


## 아직 다루지 않은 내용

시간에 따른 강도 회복, 미세구조·점토광물·시멘트화·염분·흡수력의 정량 관계, 실제 불교란 시료 품질 판단 및 다른 강도시험은 남겨둔다. 침수 속도·활성층·수축·반복 건습·팽윤압 자료·불포화 구성모형도 별도 범위다. 생성·퇴적·풍화·유기질·잔적토·분산성·슬레이킹·지역 지질 맥락이 이 실험으로 전부 구현된 것은 아니다.
