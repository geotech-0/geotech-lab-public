# 기초하중과 지정층의 압축

기존 `layered-settlement` 메뉴의 `footing` 질문이다. 기존의 넓은 균등재하 기여도와 단일 계측값 역산 질문을 보존한다. 지중응력 실험과 침하 실험 사이의 연결을 같은 메뉴 안에 둔다.

## 학습 범위

지표에 작용하는 유연한 B×L 직사각형 등분포 압력의 **중심선** 수직응력 증가를 기존 `RectangularStress.rectangle`로 계산한다. 이 응력곡선을 지정한 두 압축층에서 `Δσ′/M`로 나눈 뒤 깊이 적분한다. 배수 완료와 `Δu=0`을 가정하여 `Δσ′=Δσ`로 둔다.

- Q를 고정하고 면적을 늘리는 경우와 q를 고정하는 경우를 구별한다. 유지 조건을 바꿀 때 현재의 실제 Q/q를 먼저 보존한다.
- 시작깊이 z₀는 **지표부터 첫 압축층의 상면**이다. 첫 층은 z₀~z₀+H₁, 둘째는 그 아래 H₂이다.
- M₁·M₂는 일정한 1D 구속계수이며 Young 탄성계수 E가 아니다. 응력장에는 M을 넣지 않는다.
- 결과는 지정 구간의 중심선 압축량 합계다. 생략한 상·하부 지층을 0변형으로 가정해 전체 기초침하를 계산한 것이 아니며, 면적 평균침하·층상 탄성해·강체 기초 접지압 재분배가 아니다.
- 각 층의 평균 응력은 층 중간점 하나가 아니라 실제 깊이곡선을 적분하여 구한다. 지정 구간 하단에 남는 응력도 표시해 합산 구간 끝을 자동 영향깊이로 오해하지 않게 한다.
- Q 또는 q, 관찰 범위의 나머지 물리 입력에 오류가 있으면 이전 결과를 남기지 않는다. 선택하지 않은 Q/q와 다른 질문의 관측값·균등 상재압 오류는 격리한다.

## 근거와 교육용 단순화

[USACE EM 1110-1-1905 (2025)](https://publibrary.sec.usace.army.mil/api/download?filename=EM+1110-1-1905_Geotechincal+Design+of+Shallow+Foundations+on+Soils_2025+07+22+-+Final.pdf&id=54658636-77d2-48df-f26b-5295a01899a7&preview=true), §6–7 및 §7–10c–d, 식 7–10·표 7–4, 본문 pp.163–165: 응력 영향계수와 구속계수를 이용한 층별 압축 합산의 근거. 본 도구는 이 관계를 보여주는 단순화이며 DMT 자료에서 M을 추정하거나 문서의 설계 절차 전체를 재현하지 않는다. 원문은 영향 구간 전체를 고려하도록 하지만, 이 도구는 사용자가 선택한 두 층만 계산하므로 결과명을 “지정층 압축 합계”로 제한한다.

[FHWA-HRT-15-080, §3.5](https://www.fhwa.dot.gov/publications/research/infrastructure/structures/bridge/15080/003.cfm): 점하중 탄성해의 면적적분과 균질·등방·선형탄성 반무한체 가정. 이 도구에서도 강성이 다른 층을 입력했다고 응력장이 층상 탄성해로 바뀌지 않는다.

```text
q = Q/(BL)
Δσz(z) = ∫A 3qz³/[2π(x²+y²+z²)^(5/2)] dA
Δu=0 → Δσ′z=Δσz
εz(z) = Δσ′z(z)/Mi
si = ∫top_i^bottom_i Δσ′z(z)/Mi dz
   = (depth-average Δσ′i) Hi/Mi
selected compression = s1+s2
```

근입·굴착 제거응력, 지하수 변동, 지지력, 응력이력, 시간별 압밀, 크리프, 강체기초 강성, 횡변형·전단변형은 포함하지 않는다. 예제값은 현장 채택정수가 아니다. 각 층 상단의 국부 `Δσ′/M`가 10%를 넘으면 일정 강성 모형 범위 밖으로 표시한다. 10%는 학습 모형의 자체 제한이며 설계 허용기준이 아니다. 양의 직사각형 압력 중심선 응력은 깊이에 따라 감소하므로 각 층 상단이 그 층 최대 국부 변형률을 준다.

## API

`LayeredFooting.loadState(data)`는 치수·선택한 하중만 계산한다. 층 물성 오류가 있더라도 유효한 현재 하중을 보존하며 Q/q 유지 조건을 전환할 수 있다. 하중 자체가 무효하면 유지 조건을 그대로 둔다.

`LayeredFooting.solve(data, rectangleSolver = RectangularStress.rectangle)`는 `layers[]`, `profile[]`, `totalMm`, `integrationErrorMm`, `lowerBoundaryStress` 등을 반환한다. 테스트에서 독립 함수 주입이 가능하고 실제 앱은 기존 Boussinesq 직사각형 엔진을 사용한다.

| 필드 | 기본값 | 화면 범위 / 단위 |
|---|---:|---|
| footingWidth | 2 | 0.5–8 m |
| footingLength | 3 | 0.5–12 m |
| footingLoadMode | force | force / pressure |
| footingLoad | 600 | 0 이상 kN; 슬라이더 초기 0–6000 |
| footingPressure | 100 | 0 이상 kPa; 슬라이더 초기 0–600 |
| layerStart | 1 | 0–12 m |
| h1 / h2 | 2 / 4 | 0.5–8 / 0.5–12 m; 기존 질문과 공유 |
| m1 / m2 | 10000 / 5000 | 500–30000 kPa; UI는 MPa |

Q/q는 직접 입력에 따라 슬라이더 범위가 확장되며 변환된 Q 또는 q를 인위적 숫자 상한 때문에 바꾸지 않는다. 물리적 유효성·변형률 조건은 별도로 검사한다. 질문 간 공유되는 층두께와 M은 그대로 유지한다.

## 수치 방법과 검증

직사각형 영역 적분은 기존 엔진의 폐형식이다. 깊이 적분은 영향계수 `I(z)`에 적응 Simpson을 적용하며, 각 층의 절대 허용오차는 `1e-9 m`, 재귀 한도는 22다. 수렴하지 않거나 비유한 결과이면 오류를 반환한다. 오차 추정치는 압축량 단위로 변환하지만 실제 지반 예측오차를 뜻하지 않는다.

`tests/layered-footing.test.mjs`의 18개 검사는 다음을 확인한다.

- **독립 적분:** 점하중 커널을 깊이 방향으로 해석적분한 뒤 직사각형 면적을 2D Simpson으로 적분한다. 구현의 모서리 폐형식을 재사용하지 않는다. 기본값과 비대칭·깊은 층 조건에서 80×80→160×160 수렴 및 결과를 비교한다.
- 넓은 재하면에서 균등 `qH/M`로 접근, 무재하, 하중 선형성, 한 층 M을 2배로 했을 때 그 층만 반으로 감소.
- Q/q 유지에 따른 폭 효과, 깊은 압축층의 감소, 같은 M인 층의 분할 위치 불변, 동일 두께에서 연약층 순서 효과, B/L 회전 및 기하 상사.
- 국부 변형률 제한, 잘못된 활성 입력, 비활성 입력 격리, 지원 치수의 극단 조합, 기존 질문 보존, 유지 조건 전환 및 기준 형상·응력곡선 표시.

대표값: B=2 m, L=3 m, Q=600 kN, z₀=1 m, H₁=2 m, M₁=10 MPa, H₂=4 m, M₂=5 MPa.

| 조건 | q (kPa) | 첫 층 (mm) | 둘째 층 (mm) | 지정층 합계 (mm) |
|---|---:|---:|---:|---:|
| 기본 | 100 | 9.133813 | 9.433191 | 18.567004 |
| B=4 m, Q 유지 | 50 | 6.304665 | 8.412783 | 14.717448 |
| B=4 m, q 유지 | 100 | 12.609331 | 16.825566 | 29.434897 |

그림은 재하폭·두 층 구간과 중심선 응력곡선을 같은 깊이 축으로 표시한다. 단면 가로 범위는 8 m로 고정하여 폭 변화가 눈에 보이게 하고 세로 축은 선택 깊이에 맞춘다. 가로·세로 척도는 다르며 L은 화면 바깥 방향이다. 기준 비교에서는 저장한 재하폭·층경계·응력곡선을 실제로 그린다. 수치와 지층 구간을 우선하며 임의 파괴선이나 침하 변형을 과장해 그리지 않는다.

화면 변경 시에는 1440·768·390 px에서 유지 조건 전환, B와 M₁ 변경, 무재하·국부변형률 초과, 질문별 오류 격리, 입력 파일 미리보기·적용·복원, 축·슬라이더 동기화와 수평 넘침을 별도로 확인한다. 자동 계산 검사는 실제 학습자 검증을 대신하지 않는다.
