# 원호 절편법 독립 검토

검토일: 2026-09-22. 구현 파일을 수정하지 않고 공식 간행물의 동일 원문과 별도 Python 계산으로 검토했다.

## 출처와 식

- [USACE EM 1110-2-1902, Slope Stability (2003), 공식 PDF](https://www.publications.usace.army.mil/Portals/76/Publications/EngineerManuals/EM_1110-2-1902.pdf). 공식 서버 직접 열람은 403; 검색 색인과 [University of Washington에 보관된 동일 USACE 원문](https://faculty.washington.edu/kramer/522/ArmySlopeStabilityManual.pdf)을 대조했다. 아래 페이지는 문서에 인쇄된 번호다.
- C-13 식 C-12 및 C-14 설명: 외력이 없는 권장 Ordinary 식은 `F = Σ[c′ℓ + (W cosα − uℓ cos²α)tanφ′] / ΣW sinα`. `ℓ=b/cosα`이므로 유효법선력 항은 `(W−ub)cosα`. C-14의 다른 식 C-13(`Wcosα−uℓ`)은 수압이 클 때 비현실적 음수응력을 낼 수 있어 권장하지 않는다. UI에는 **Ordinary · USACE 수압식**으로 구분한다.
- F-6 식 F-4/F-5와 F-7 식 F-6: 외력이 없으면 `F = Σ[(c′b+(W−ub)tanφ′)/mα] / ΣWsinα`, `mα=cosα+sinαtanφ′/F`. **본문 C-16 식 C-15의 수압 항에는 Appendix F와 다른 secα가 보이므로, 실제 구현 출처는 일관된 Appendix F를 인용한다.**
- F-3 부호: α는 사면 하향과 같은 방향이면 양수. 현재 앱은 오른쪽으로 지표가 올라가므로, 왼쪽으로 움직이는 절편의 α가 양수다. 원호 바닥의 접선각을 사용하며 `b`는 수평 폭이다.
- C-15~C-18: Ordinary는 절편 사이 힘을 생략하고 전체 모멘트만 맞춘다. Simplified Bishop은 절편 사이 전단력을 생략하고 절편 수직 힘 평형과 전체 모멘트 평형을 맞추며, 수평 힘 평형은 만족하지 않는다. Ordinary가 항상 보수적이라는 보장은 없다.
- C-34~C-38: 음수 법선력, 비정상적으로 큰 힘, 특이 분모, 비수렴·복수해는 해 수용성을 검토해야 한다. 점착력으로 생긴 인장을 수용할 수 없다면 인장균열 등 다른 모델이 필요하다.
- C-8: 서로 다른 해석법의 최소 활동면도 달라질 수 있다. 균질한 `c′=0` 사면은 최소 원호가 무한 반경의 평면에 접근할 수 있다. 제한된 원호 격자의 최소값을 전역 최소값으로 표시하지 않는다.

## 독립 유도와 구현 판단

외력이 없는 Bishop 절편의 수직 힘 평형은 다음이다.

```
W = (N′ + uℓ)cosα + [(c′ℓ + N′tanφ′)/F]sinα
N′ = [W − ub − (c′b/F)tanα] / mα
```

따라서 `mα>0`, 수렴 잔차, `N′≥0`를 각각 확인해야 한다. 음수 `N′`를 0으로 바꾼 뒤 같은 식의 해라고 표시해서는 안 된다. 수렴한 양의 안전율도 인장이 있으면 이 앱의 허용 모델에 맞지 않는다.

`Aᵢ=c′bᵢ+(Wᵢ−uᵢbᵢ)tanφ′`가 양수인 경우, `Σ Aᵢ/(Fcosαᵢ+sinαᵢtanφ′)−ΣWᵢsinαᵢ`는 모든 분모가 양수인 F 구간에서 단조 감소한다. 이 구간에서의 bracketing은 잘못된 특이점 가지를 피할 수 있다. 0 강도는 별도로 처리한다.

현재 `ru=ub/W`는 절편 평균 상재응력에 대한 **지정 수압비**다. 수면선·유선·정상 침투를 푼 결과가 아니다. 총단위중량 γ와 수압비를 따로 바꾸므로 `ru` 조정 때 중량이 자동으로 바뀌지 않는다는 설명이 필요하다.

## 최종 읽기 전용 엔진 감사

원 중심/하부 원호, 좌향 활동의 α 부호, 절편 폭, 총중량, 수압비, 두 방법의 식과 Bishop N′를 독립 검산했다. UI 범위에 해당하는 3,888개 조합 중 양의 Bishop 결과가 수용된 1,778개를 추가 확인했으며, 유한수 오류는 없고 절편별 수직 힘 평형의 최대 절대 잔차는 `3.6e−13 kN/m` 미만이다.

**수정 요청 한 건:** `totalA===0`에서 F=0은 전단강도가 없다는 별도 상태다. Bishop의 F로 나누는 식은 이때 정의되지 않는다. 기존 편의 처리인 `mα=cosα`, `N′=(W−ub)/cosα`를 유일한 Bishop 평형해나 수렴 검증값으로 표시하면 안 된다. UI에는 전단강도 0에 따른 F=0만 별도로 설명하고, Bishop mα·N′·잔차는 계산하지 않은 상태로 표시하도록 root 및 엔진/UI 담당에게 전달했다. 엔진에서도 해당 필드는 null이 적절하다.

UI의 ru 상한 .6을 넘어서는 ru=.9 등에서는 양의 mα라도 매우 작아 비정상적으로 큰 법선력이 발생할 수 있다. 이 범위를 확장한다면 수렴과 N′ 부호 검사만으로 수용성을 확정하지 말고 별도 해석 검토가 필요하다.

공개 예제는 EM Fig F-11(F-21), 본문 F-20의 건조 총응력 사례 `F=1.33`을 확인했다. 그러나 인쇄된 표의 폭·길이·각도 관계가 정밀 복사 검증에 적합한지 추가 확인이 필요하므로, 이 숫자를 현재 단순 균질 원호의 benchmark로 주장하지 않는다.

## 화면에 필요한 설명

- 두 안전율은 **같은 원호·같은 절편·같은 입력**의 평형 가정 차이다. 차이를 정확도나 설계 여유의 확정값으로 해석하지 않는다.
- 13×13 격자 탐색은 지정된 진입점/원 중심 높이 범위에서의 Bishop 후보 비교다. 고정된 사면 끝점, 비원호·다층·인장균열 누락과 범위 끝 최소 여부를 표시한다.
- F=1은 이 모델에서의 저항과 활동의 균형이며 설계 적합 판정이나 실제 붕괴 확률이 아니다.
- 힘 화살표와 원호는 정량적 형상을 보여 주되 변위·파괴 후 거동을 계산한 것처럼 애니메이션하지 않는다.
