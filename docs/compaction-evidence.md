# 다짐에너지 비교 자료

기존 `compaction` 화면의 자료 선택에 USACE의 같은 흙에 대한 다짐 횟수별 시험자료를 추가했다. 새 메뉴나 같은 계산의 질문 탭은 만들지 않았다. 기존 합성 5점과 습윤→건조 환산·지정 MDD에 대한 현장 비교는 그대로 유지한다.

## 원자료·재사용·보관

원문은 [USACE EM 1110-3-141, Airfield Flexible Pavement—Mobilization Construction (1984-04-09)](https://www.publications.usace.army.mil/portals/76/publications/engineermanuals/em_1110-3-141.pdf), Figure 3-1, 인쇄 p.3-3, PDF 20번째 페이지다. 공식 USACE 자료 목록 및 색인에서 문헌과 그림을 확인했다. 공식 PDF 직접 요청은 403으로 실패해 [동일 문헌의 공개 사본](https://www.pdhonline.com/courses/c302/EM1110-3-141.pdf)을 받아 도면을 직접 확인했다. 사본은 표지·문서번호·일자·쪽번호·기관 표기와 공식 색인의 그림 내용을 대조했다. 공식 서버 파일의 바이트 동일성은 확인하지 못했으므로 SHA는 **받은 사본**의 것이다.

- 원 PDF 사본 SHA256: `3f4f78c4397fe8e827ebfa8cb7904e79c249a2707cd04b9535ebd6a46b6ffc0d`.
- 공개 배포본에는 원본 문서와 발췌 PDF 페이지를 포함하지 않는다. 원문은 위의 제공기관 링크와 식별된 공개 사본에서 확인한다.
- `assets/compaction/usace-em1110-3-141-points.json`은 모든 판독점의 원단위·픽셀 좌표·보정 눈금·원문/사본 URL·원 PDF 및 추출 페이지 SHA·판독 한계·재사용 근거를 가진다.

[USACE Privacy and Security](https://www.usace.army.mil/Privacy-and-Security/)의 2항은 별도로 지정한 경우를 제외한 공개정보의 복사·배포를 허용하고 출처 표기를 요청한다. 이 페이지는 U.S. Army Corps of Engineers를 도면 출처로 표시하며 별도 제3자 저작권 고지·재사용 제한을 담고 있지 않다. 수치화 기록에는 이 공개정보 정책을 재사용 근거로 기록한다. 공식 정책 페이지를 다시 확인하는 요청은 접근 제한으로 완료하지 못했다. PDF 페이지와 원그림은 배포하지 않으며 Creative Commons 라이선스가 부여되었다고 표시하지 않는다. 기관 로고·승인 표시는 만들지 않으며, 출처와 자체 수치화라는 점을 설명한다.

## 어떤 점을 옮겼는가

대상은 Figure 3-1의 왼쪽 아래 **A 도표**다. 같은 실트질 점토 CL, LL=37, PI=14에 대한 MIL-STD-621 Method 100의 12·26·55회/층 계열이다. 빈 삼각형·사각형·원 기호 20개의 중심을 판독했다. 검은 채움 기호의 침수 후 밀도 계열, CBR의 B·C 도표, 원문에서 매끈하게 연결한 선의 정점은 사용하지 않았다.

| 회/층 | 함수비 w (%)의 판독값 | 건조밀도 (lb/ft³)의 판독값 |
|---|---|---|
| 12 | 10.1, 12.5, 13.7, 15.7, 16.9, 18.2, 19.9, 21.5 | 95.5, 98.5, 100.5, 103.5, 104.5, 104.0, 103.0, 101.0 |
| 26 | 10.0, 12.5, 13.7, 15.3, 17.9, 19.9 | 102.5, 107.0, 109.0, 111.0, 108.0, 105.0 |
| 55 | 10.0, 12.5, 14.2, 15.6, 17.3, 19.9 | 109.5, 114.0, 116.0, 115.0, 112.0, 106.5 |

원래 시험의 디지털 기록이나 정밀한 수치표가 아니다. 이 표의 모든 숫자는 스캔 기호에서 읽은 **근삿값**이다.

2552×3303 픽셀의 원 PDF 내 이미지를 읽었다. A 도표의 눈금은 x=438에서 w=5%, x=1112에서 25%, y=1297에서 90 lb/ft³, y=800에서 120 lb/ft³로 선형 보정했다.

```
w = 5 + (pixelX−438)·20/(1112−438)
ρd,pcf = 90 + (1297−pixelY)·30/(1297−800)
```

w는 0.1%p, ρd는 0.5 lb/ft³까지 반올림했다. 약간 기울어진 스캔·두꺼운 기호·해칭 중첩을 고려한 판독 여유는 w±0.3%p, 밀도±0.75 lb/ft³다. 후자는 약 ±0.12 kN/m³다. 이는 판독에 관해 보수적으로 정한 표시 한계이며 통계적 신뢰구간·계측기 오차·재료 편차를 정량화한 것이 아니다.

단위 환산은 lb 질량에 표준중력을 곱하는 방식이다.

```
1 lb/ft³ × 0.45359237 kg/lb × 9.80665 m/s² ÷ (0.3048 m/ft)³ ÷ 1000
= 0.1570874638462462 kN/m³
```

UI는 원그림의 dry density를 환산한 건조단위중량 γd로 표시한다. 계수의 자릿수가 판독 정확도를 뜻하지 않도록 결과는 주로 소수 첫째 자리의 약값으로 보여준다.

## 계산·화면 계약

`src/compaction-evidence.mjs`는 독립된 `CompactionEvidence` namespace다. 기존 `StateModels.compaction()`과 합성 자료를 변경하지 않는다.

```js
CompactionEvidence.solve({effort: '55', observeW: 15})
```

- `effort`는 문자열 또는 수치 12·26·55만 허용한다. 사이 횟수의 새 곡선을 생성하지 않는다.
- `observeW`는 세 계열의 공통 범위 10.1~19.9%의 유한 숫자다. 외삽하지 않는다.
- `series`는 3개 고정 계열과 `sampledPeak`를 반환한다. 원자료 배열·각 행은 동결되어 입력 조작으로 바뀌지 않는다.
- `readings`는 같은 관찰 함수비에서 3계열의 값이다. 원 판독점이면 `kind:'digitized-test-symbol'`, 사이를 읽으면 `kind:'straight-connector'`다.
- `selected`, `atWater`, `highMinusLow`는 선택한 계열·그 관찰값·55회와 12회의 차이다.
- 정상은 `{valid:true,errors:[]}`, 자료 범위·형식 오류는 `{valid:false,errors:[...]}`다.

`CompactionEvidenceView`는 3곡선을 모두 그리고 선택 계열을 강조한다. 조작은 자료 모드 선택·횟수 선택·관찰 함수비의 세 가지다. 점 사이는 직선 연결이며, 현재 선택 위치를 검은 원으로 표시한다. 자료를 바꿀 때 입력 Gs·현장 습윤단위중량·지정 MDD 등 비활성 필드를 검사하지 않도록 descriptor의 `activeFields`를 제공한다.

시험점의 최고값과 그 함수비는 매끈한 곡선을 맞춘 **MDD·OMC와 구분**한다. 원문의 95% modified 최대밀도 110.6 lb/ft³ 표기에서 역산되는 곡선 최대밀도는 약 116.4 lb/ft³지만, 여기의 55회 **판독 시험점** 최고값은 116.0 lb/ft³다. 서로 다른 근거의 숫자를 덮어쓰거나 같게 맞추지 않는다. 기준시험 결과를 결정하는 실무 곡선 피팅은 구현하지 않았다.

이 모드는 Gs가 주어지지 않은 원문에 임의의 비중이나 ZAV를 덧붙이지 않는다. 횟수를 에너지 kJ/m³로 자동 바꾸거나 각 계열을 현행 ASTM 표준/수정 시험과 동일하다고 단정하지 않는다. 이 흙에서 보이는 경향을 다른 흙의 정량적 예측식으로 확장하지 않는다. 시험의 토질·방법·조건이 다른 자료를 섞지 않는다.

`comparisonPlot:false`다. 저장 조건의 실제 곡선은 덧그리지 않으며, 같은 모드의 저장 결과만 수치 비교한다. 합성↔원문 모드 사이에는 다른 의미의 기준값을 자동 비교하지 않는다.

## 검증

`node --test tests/compaction-evidence.test.mjs tests/state-models.test.mjs`로 자료·상태관계 검사를 실행한다.

검증은 20행의 원단위·JSON·런타임 일치, 픽셀 보정 및 반올림 재현, 단위 환산 독립값, 각 계열 시험점 최고값, 정확한 자료점 반환·직선 보간 구분, 고정 계열 불변, 선택 범위와 외삽 거절, 동결 자료 보호를 포함한다. 발췌 PDF가 없는 명시적 공개 배포본에서는 PDF SHA 검사 1개를 건너뛴다. 선택 숫자의 일치 검사는 원본 파일의 바이트 재대조가 아니다. [검증 범위](validation.md)를 참고한다. descriptor 검증은 세 횟수와 함수비 5개 조합 15조건에서 숨긴 합성 입력이 오류여도 원문 모드를 정상 계산·렌더하는지, 반대 모드의 저장 조건이 비유한 값으로 섞이지 않는지 확인한다.

화면 변경 시에는 실제 앱에서 데스크톱과 390px 폭으로 세 곡선의 기호·색·선택값과 외부 원문 링크가 읽히고 작동하는지 확인한다. 이 검증은 원문 판독값을 원 계측 기록의 정밀도로 검증한 것이 아니다.
