# 삼상관계·상대밀도·다짐 학습 모형

검증일: 2026-09-22. 구현: `StateModels` 네임스페이스와 `StateLabs`의 `phases`, `relative-density`, `compaction`.

## 입력·단위 계약

- 함수비 `w`, `fieldW`, `referenceOMC`, 자료의 `w`는 **퍼센트 숫자**이다. 예: `12`는 12%이며 식에서 0.12로 변환한다.
- `e`, `emin`, `emax`, `Gs`는 무차원이다.
- `gammaW`, 모든 `gamma*`, `referenceMDD`는 kN/m³이다. 물의 기본 단위중량은 9.81 kN/m³.
- 포화도·간극률·상대밀도·상대다짐도 반환값은 0~1을 통상 범위로 하는 **비율**이며, 화면에서 100을 곱해 %로 표시한다. 상대다짐도는 기준시험에 따라 1을 넘을 수 있으며 임의로 잘라내지 않는다.
- 숫자 문자열, NaN, 무한대, 불가능한 부피 조건은 실패 결과 `{valid:false,errors:[...],warnings:[]}`를 반환한다. 이전 결과로 대체하지 않는다.

## 1. 삼상관계

`StateModels.phases({e=.65,Gs=2.65,w=15,gammaW=9.81})`

`wf=w/100`으로 놓고 다음 항등식을 사용한다.

- `S=wf·Gs/e`, `n=e/(1+e)`.
- `γd=Gs·γw/(1+e)`, `γ=γd(1+wf)`.
- `γsat=(Gs+e)·γw/(1+e)`, `γ′=γsat−γw`.
- 도형의 기준은 `Vs=1 m³`, `Vv=e`, `Vw=wf·Gs`, `Va=e−Vw`이다.
- 같은 기준에서 `Ws=Gs·γw kN`, `Ww=Vw·γw kN`; 공기 중량은 무시한다.

부피 막대는 전체 부피에 대한 실제 구성비이고 중량 막대는 전체 중량에 대한 실제 구성비이다. 두 막대의 총 높이가 같아도 각기 다른 단위와 총량으로 정규화했음을 그림 아래에 명시한다. 두 막대 사이 높이를 직접 물리적 길이로 비교하지 않는다.

`e>0`, `Gs>0`, `γw>0`, `w≥0`과 `wf·Gs≤e`를 검사한다. 불가능한 포화도를 100%로 보정하지 않는다. `γ′`는 포화 상태의 부력 보정 단위중량이며 현재 불포화 `γ−γw`로 계산하지 않는다. 팽윤·수축·응력에 따른 골격 변형을 예측하는 구성모형은 아니다.

독립 검산 예: `e=.5, Gs=2.5, w=10, γw=10`에서 `S=.5`, `n=1/3`, `γd=16.6667`, `γ=18.3333`, `γsat=20`, `γ′=10 kN/m³`. `w=20%`이면 포화, 그보다 높으면 실패한다.

## 2. 상대밀도

`StateModels.relativeDensity({e=.65,emin=.4,emax=.9,Gs=2.65,gammaW=9.81})`

`Dr=(emax−e)/(emax−emin)`를 사용한다. `γd,min=Gs·γw/(1+emax)`, `γd,max=Gs·γw/(1+emin)`이다. 단위중량 표현으로 계산한 `[(γd−γd,min)/(γd,max−γd,min)]·γd,max/γd`와도 일치하는지 검사한다.

서로 같은 흙과 시험법의 양 끝 값을 전제로 한다. `0≤emin<emax`, `emin≤e≤emax`를 요구한다. 이 도구는 시험 기준 바깥의 지표를 해석하는 도구가 아니므로 해당 경우 수정 안내와 함께 계산을 중단한다. 원래 측정값을 억지로 0~100%에 잘라 넣지 않는다.

그림의 세 기둥은 모두 같은 `Vs=1`과 동일한 부피 척도를 쓴다. 따라서 현재 간극비 감소가 전체 부피 감소로 보인다. 상대밀도와 상대다짐도를 혼동하지 않도록 결과와 설명을 별도 실험으로 분리했다.

검산: `e=.9→Dr=0`, `e=.4→Dr=1`, `e=.65→Dr=.5`.

## 3. 다짐과 함수비

`StateModels.compaction({fieldW=12,fieldGammaWet=20,Gs=2.65,referenceMDD=18.5,referenceOMC=12,gammaW=9.81,samples=sampleData})`

주요 식:

- `γd,field=γwet/(1+fieldW/100)`.
- `Rc=γd,field/referenceMDD`.
- `γd,ZAV=Gs·γw/(1+Gs·w/100)`.
- `e=Gs·γw/γd,field−1`, `S=(fieldW/100)Gs/e`.
- 공기부피비 `Va/V=[e−(fieldW/100)Gs]/(1+e)`.

`zeroAirVoids({w,Gs,gammaW})`는 ZAV 값을 반환하고 잘못된 입력은 `null`을 반환한다. ZAV는 최대 시공성능이나 목표 다짐도를 뜻하지 않는다. 공기부피가 0인 물리적 상한이다.

기본 참고 자료는 다음과 같은 **교육용 합성값**이다. 실제 시험으로 취득한 자료가 아니다.

| 함수비 % | 습윤 단위중량 kN/m³ | 환산 건조 단위중량 kN/m³ |
|---:|---:|---:|
| 6 | 17.278 | 16.3 |
| 9 | 19.293 | 17.7 |
| 12 | 20.720 | 18.5 |
| 15 | 20.930 | 18.2 |
| 18 | 20.296 | 17.2 |

화면은 다섯 점을 직선으로 연결한다. 선분 사이의 값은 시험값이나 예측값으로 반환하지 않는다. 곡선 적합, 에너지 슬라이더에 따른 MDD·OMC 예측, 합격 판정은 구현하지 않는다. 기본 MDD와 OMC는 예제 최고점과 같지만 사용자가 별도 기준값을 입력할 수 있다. 변경된 기준이 합성자료 최고점과 다르면 화면에서 분명히 알리고 합성곡선을 자동으로 조작하지 않는다.

Gs 변경은 ZAV와 현재 포화도 계산에만 반영하며 참고자료의 건조단위중량을 바꾸지 않는다. 변경한 Gs와 자료점이 양립하지 않으면 실패한다. 현장점·자료점·기준 MDD/OMC가 모두 ZAV 이하인지 검사한다. `e≤0`인 무간극 고체는 이 학습 모형의 대상에서 제외한다.

기본 현장점 검산: `γd=20/1.12=17.857142857 kN/m³`, `Rc=17.857142857/18.5≈0.965251`.

## 근거와 해석상 구분

- [FHWA NHI-05-037, Chapter 5, §5.3](https://www.fhwa.dot.gov/engineering/geotech/pubs/05037/05a.cfm): Table 5-8의 부피·중량 관계, Eqs. 5.1–5.4의 건조환산·다짐도, Eqs. 5.5–5.6의 상대밀도, ZAV 설명. HTML Table 5-7의 간극률 설명은 부피 분모·분자 표현이 부정확하므로 본 구현은 정의 `n=Vv/V=e/(1+e)`를 쓴다.
- [FHWA NHI-05-037, Chapter 7, Compaction](https://www.fhwa.dot.gov/engineering/geotech/pubs/05037/07b.cfm): 지정 다짐에너지에서의 함수비–건조단위중량 관계와 실내 기준시험의 역할.

위 출처의 자료 곡선이나 그림을 복제하지 않았다. 삼상 및 간극비 도형은 산출된 부피비를 그리며, 다짐 5점은 별도로 정한 합성 자료다. 다짐은 기계적인 에너지로 공기 간극을 줄이는 과정, 포화토 압밀은 과잉간극수압 소산과 체적 변화의 시간 과정을 주로 다룬다는 학습 구분을 표시한다. 이 실험에서는 어느 과정도 시간·시공에너지에 대해 수치 예측하지 않는다.
