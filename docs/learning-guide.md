# 흙의 감각

토질·기초공학을 배웠던 사람이 입력값을 함께 바꾸며 관계를 다시 익히는 학습 실험실입니다. 학습과 프로젝트 계산서의 입력·저장을 분리하고, 종합 설계 적합 판정은 제공하지 않습니다.

40개 학습 메뉴에 짧은 복습 경로·내 예제와 침강 입경 실험을 연결했습니다. 별도 **계산서** 화면은 직사각형 얕은기초의 하중 장부·한 방향 접촉·지지력과 외부 침하 검토값을 정리합니다. [검증 범위와 재실행 방법](validation.md)을 확인할 수 있습니다. 실제 학습자 연구·외부 전문가 승인은 미실시입니다.

## 실행

Node.js 22 이상과 npm을 준비하고 저장소 루트에서 실행합니다. `npm ci`는 잠금 파일에 고정된 의존성을 설치하며, 전체 테스트에 필요한 `jose`도 포함합니다.

```sh
npm ci
npm test
npm run build
npm start
```

주소는 `http://127.0.0.1:8766/`입니다. 로컬 서버는 빌드한 `dist-public/index.html`을 제공합니다. 입력·선택 질문·비교 기준은 현재 브라우저의 로컬 저장소에 보존합니다. 파일 주소와 서버 주소는 별도 저장공간을 사용할 수 있습니다. 로컬 서버의 `/api/`는 비활성 상태로 응답하므로 클라우드 동기화는 제공하지 않습니다.

빌드한 `dist-public/index.html`에는 계산 코드·화면·Pretendard·사용한 시험자료가 포함되어 있어 파일로도 열 수 있습니다. 외부 원문 링크를 열 때는 인터넷이 필요합니다. 생성된 HTML은 직접 수정하지 않고 `src/`의 소스를 수정한 뒤 다시 빌드합니다.

실험 제목의 존재가 해당 전문 분야 전체의 구현 완료를 뜻하지 않습니다. 각 화면의 적용 가정과 [개별 모형의 근거](reference-map.md)를 함께 확인할 수 있습니다.

## 조작 원칙

- 관련 입력을 슬라이더·직접 숫자로 함께 바꿉니다. 단위와 고정·연동 조건을 표시합니다.
- **다른 학습 질문**은 필요한 입력·계산·해설을 바꿉니다. **같은 해의 다른 그림**은 그림 옆의 표시 선택으로 구별합니다.
- 유효응력은 중복 질문을 통합하고 수위·하중·동시 변화의 실제 A/B 예제를 제공합니다. 사용자가 정한 지층·물성과 관찰 깊이를 유지하며 두 상태의 같은 깊이를 비교합니다.
- 기준값은 직접 변경할 때까지 고정합니다. 달라진 입력에 기준값을 표시하고, 유효하지 않은 현재 결과를 과거 정상값으로 대체하지 않습니다.
- 기본 화면에 핵심식·현재 대입값·변화 이유를 표시합니다. 전체 유도·적용 범위·출처는 펼쳐 봅니다.
- 문맥 기호 도움, 그래프 확대, 검색의 질문 바로가기, 되돌리기, 예제 복귀, 로컬 복원을 지원합니다.
- 실제 시험자료의 커서는 기록을 탐색합니다. 밀도·CSR을 임의로 바꾸어 측정되지 않은 응답을 생성하지 않습니다.

두 입력의 결합은 유효응력·얕은기초·1차압밀의 **두 값의 관계**에서 한눈에 볼 수 있습니다. 선택한 조건은 확인 후 본 화면에 함께 적용하며 한 번에 되돌릴 수 있습니다. [관계면의 가정과 단위](relationship-maps.md)를 기록했습니다.

**입력 저장 / 파일 열기**로 현재 실험의 입력·질문·비교 기준을 JSON으로 옮깁니다. 미리보기에서 내용을 확인해야 적용되며 다른 실험은 유지합니다. [파일 형식과 복원](session-files.md)을 참고하세요. 사이트·로컬 파일·서버의 저장소는 서로 달라 자동 동기화하지 않습니다.

후속 보강도 기존 메뉴 안에 통합했습니다. **층별 침하와 계측 → 기초하중은 어느 층에 전달될까**에서 B·L·Q/q·층별 H/M을 함께 조절합니다. 얕은기초 침하 화면의 연결 버튼은 폭과 하중만 옮기고 지층 물성을 유지합니다. **토압과 벽 움직임 → 점착력·인장균열**은 음의 원식과 압축 접촉을 구분하며 c′×q 관계면을 제공합니다. **말뚝과 하중전달 → 실제 재하시험**은 4TU 공개 CSV의 재하·제하·재재하 기록을 읽습니다. 입력 파일은 버전 5로 저장하고 기존 버전 1·2·3·4 파일은 공개 당시의 구조에 따른 명시적 이전 규칙으로 복원합니다.

**사면과 물의 힘 → 원호·해석법 비교**에서 H·β·c′·φ′·rᵤ와 원호 형상을 함께 바꿉니다. 같은 활동면의 Ordinary(USACE 수압 처리)와 간편 Bishop법을 비교하고, 선택 절편의 힘을 기본 화면에서 확인합니다. 후보 적용은 169개 지정 원호 중 유효한 Bishop 결과의 최소값이며 전역 최소 활동면이 아닙니다. [계산·한계·검증](circular-slope.md).

## 개인 복습과 계산서

**내 학습**에서 6개 분야의 3단계 짧은 복습을 시작합니다. 입력을 예제로 덮지 않고 현재 조건을 유지하며, 변화 예측→두 값 조절→자기 설명 순서로 복습합니다. 자기 확인은 이해도 검정이 아닙니다. **내 예제**는 최대 12개를 이름 붙여 저장하고, 미리보기·명시적 적용·전체 되돌리기를 제공합니다. 중요한 예제는 기존 JSON 파일 저장으로 옮깁니다.

**계산서**는 별도 화면·별도 저장소입니다. 1~8개 사용하중 조합의 장부·접촉·지지력을 비교하고 출처와 채택 FS를 기록합니다. JSON 초안 복원, 인쇄용 미리보기, 독립 HTML 보고서를 지원합니다. 침하는 외부 검토값·한도·근거가 모두 있을 때만 비교합니다. 침수와 편심의 결합 등 채택 절차가 확정되지 않은 경우는 해당 결과를 미검토로 둡니다. [식과 범위](foundation-worksheet.md).

실제 사람을 대상으로 한 후속 검토는 [15분 진행안](learner-validation-protocol.md), [외부 기술 검토 패킷](external-review-pack.md)에 재현 입력과 기록 양식을 준비했습니다. 아직 수행하지 않은 검토를 완료로 표시하지 않습니다.

## 출처와 모델 범위

[자료·국내 기준 연결](reference-map.md)과 개별 `docs/*.md`에 식·원문 위치·단위·검증 방법을 기록했습니다. 단순화한 모형, 지정 예제, 실제 원계측, 원그림 수치화를 서로 구별합니다. 수치화 자료에는 판독 범위를 표시합니다.

예를 들어 Prandtl 그림은 무중량 2D 띠기초 기구이며 정사각형의 실제 3D 파괴면이 아닙니다. 사면은 지정 후보면 비교이며 전역 활동면 탐색이 아닙니다. 선형 보·스프링은 실제 비선형 p–y와 다르며, 액상화 유발지표와 이후 현장 변위를 구별합니다. 모든 적용 한계를 하나의 경고창에 모으지 않고 해당 결과 옆에 설명합니다.

[검증 안내](validation.md)는 자동 검사, 원자료 대조의 한계, 별도 화면 검증을 구분합니다.

## 소스와 검증

의존성 설치 후 `npm test`로 수치·자료·저장·인증 계약을 검사하고 `npm run build`로 앱을 빌드합니다. 실행 순서는 위의 **실행** 절을 따릅니다.

`src/*.mjs`는 계산·근거자료, `src/labs/*.js`는 질문별 화면, `src/app.js`는 공통 상태와 조작입니다. `src/lab-registry.js`에 명시적으로 등록한 실험만 `source-manifest.cjs`가 빌드합니다. 미등록 초안 파일은 앱에 들어가지 않습니다. 빌드는 결합 코드의 문법과 실제 HTML 삽입 결과를 확인한 뒤 파일을 갱신합니다.

단계굴착 브라우저 검사 `tests/excavation-ux.cjs`에는 Playwright와 브라우저가 필요합니다. `PLAYWRIGHT_MODULE`, `CHROME_EXECUTABLE`, `GEOTECH_URL`로 실행환경을 지정할 수 있습니다. 실행 예는 [검증 안내](validation.md)에 있습니다. 나머지 `tests/*.test.mjs`는 `npm test`로 실행합니다.

`test-results/`는 로컬 실행 결과와 화면을 보관하는 Git 제외 경로입니다. 자동 검사는 실제 학습자의 복습 효과 검증이나 외부 전문가의 독립 검토를 대신하지 않습니다.

Pretendard 라이선스는 `assets/fonts/OFL.txt`에, 재사용 시험자료의 출처·조건·라이선스는 각 데이터 파일과 설명 문서에 포함합니다.
