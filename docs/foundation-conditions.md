# 굴착 하중 장부와 편심 접촉

2026-09-22. 두 독립 학습 질문의 계산이다. 기존 표면 정사각형의 지지력·탄성침하 모형에 검증되지 않은 계수를 덧붙이지 않는다.

## 같은 면적·같은 수위의 하중 장부

`FoundationConditions.ledger()`의 모든 길이는 m, 하중 kN, 압력 kPa, 단위중량 kN/m³이다. 입력은 B,L,Df,t,P, 습윤·포화 흙 γ, 콘크리트 γ, 수위 깊이 zw, 상부 공간(`backfilled`/`basement`)이다. Df≥t>0.

- 원지반: σv0 = γmoist·min(Df,zw) + γsat·max(0,Df−zw).
- Wf = BLtγconcrete. 전면 되메움 Wcover는 지표부터 기초 상면까지 동일 흙의 습윤·포화 중량 합계다. 빈 지하공간은 Wcover=0.
- W=P+Wf+Wcover, 기저 게이지 수압 u=γw·max(0,Df−zw), U=uBL.
- q총=W/(BL), 기저 압축 유효반력 요구값 q′=(W−U)/(BL).
- Δq=q총−σv0=q′−σ′v0. 같은 수압 기준이므로 두 순증가식이 같다.

P는 기둥에서 전달되는 하중이고 기초 자중을 포함하지 않는다. 전면 되메움은 기둥 점유 부피를 따로 차감하지 않는 명시적 단순화다. 기초의 모든 정수압 효과는 기저 수압 U와 위의 흙·물 중량으로 장부에 반영하므로 부력을 추가로 두 번 빼지 않는다. 빈 지하공간 내부는 흙·물이 없고 외부 정수압은 유지하는 조건이다.

W≤U에서는 압축 접촉으로 평형이 불가능하다. 음의 q′는 실제 흙의 인장반력이 아니며 UI가 이를 명시한다. 굴착·재하 면적이 다르거나 전후 수위가 다르면 Δq 하나로 지중응력 전체를 대신할 수 없다. 굴착 단계 시간, 배수, 지하벽 측면마찰, 앵커, 침하를 계산하지 않는다.

독립 예: B=L=3,Df=2,t=.5,P=1200,γmoist18,γsat20,γconcrete24,zw4 → Wf108,Wcover243,σv0=36,q총172.333,Δq136.333. 같은 빈 지하공간에서 P216이면 Δq0이어도 q총36 kPa다.

## 한 방향 편심의 선형 접지압

`FoundationConditions.contact({width,length,load,eccentricityRatio})`. N은 자중 등을 포함해 저면에 전달된 전체 압축 합력으로 정의하며 별도 자중을 추가하지 않는다. e=(e/B)B, M=Ne. 강체·선형 접지압·인장저항0, 한 방향 편심으로 한정한다.

- |e|≤B/6: qmax,min=N/(BL)(1±6|e|/B). x는 중심 기준이며 q(x)=N/(BL)(1+12ex/B²).
- B/6<|e|<B/2: 접촉폭 a=3(B/2−|e|), qmax=2N/(La), 반대쪽은0. 하중이 치우친 쪽에 삼각형 압축분포를 둔다.
- |e|≥B/2 또는 N≤0은 이 모형의 정적 압축 평형 범위 밖이다.
- 별도 유효면적 B′=B−2|e|, A′=B′L, N/A′도 설명한다. 이 균등환산 압력은 위 접촉분포의 qmax와 다르다.

독립 적분으로 ∫qLdx=N과 ∫xqLdx=Ne를 검증한다. 핵 경계 연속성, 반대 편심의 대칭, 크기 및 무효 입력도 검사한다. 현재 총15개 시험 통과. 지지력·침하·회전·설계 적합 판정은 이 모델의 출력이 아니다.
