# 반복재하 시험자료: 수압비와 변형의 진행

계획 v3 §3.4의 반복하중 최소 제공에 해당한다. `cyclic-evidence` 실험은 **한 시료의 실제 반복 삼축시험**에서 선택한 8개 시점을 탐색한다. 새로운 응답을 계산하는 구성모형이나 지진응답 예측기가 아니다. CSR/CRR로 액상화 유발을 검토하는 실험과 연결하되, 수압 지표·시험 변형 기준·현장 발생 후 결과를 구별한다.

## 보존한 자료와 재계산

`assets/data/cyclic-leap2017-csr0325.tsv`는 내려받은 파일의 **바이트를 그대로** 보존했다. 헤더 뒤에 6,001개 측정 행이 있으며 시간 범위는 0~100분이다.

```
SHA-256: 4ba2335dbfa992c86670f4612b56579f102110404daa5901f285f7d056d96e85
```

6개 원래 열은 `time_min`, `eps_a`, `eps_v`, `sigmaP_3_kPa`, `sigma_3_kPa`, `sigma_d_kPa`이다. 변형률 단위는 %, 응력은 kPa. 앱은 첫 2,521개 기록(0~42분)을 그대로 내장한다. 시간·응답을 보간하거나 곡선 맞춤으로 생성하지 않는다. 측정점 사이를 잇는 SVG 선은 기록의 시각화이며 임의 시점의 예측값을 API로 제공하지 않는다.

수압비는 아래처럼 **원자료의 총·유효 구속압**으로 계산한다.

```
u0 = σ3,0 − σ′3,0 = 169.4 − 99.74 = 69.66 kPa
u(t) = σ3(t) − σ′3(t)
Δu(t) = u(t) − u0
ru(t) = Δu(t) / 99.74
σ′3(t) = 99.74 + [σ3(t)−169.4] − Δu(t)
```

총구속압의 작은 변화가 있으므로 `ru>1`인 일부 기록에서도 σ′3가 양수일 수 있다. 입력을 강제로 100 kPa에 맞추거나 ru를 [0,1]로 자르지 않는다. 원자료의 초기 εa=-0.004624%도 0으로 재조정하지 않는다. 표시 자릿수를 계측 정확도라고 주장하지 않는다.

**배포 그림과의 정의 차이:** 원데이터에 함께 배포된 `PlotExpResults.m`은 p′=σ′3+q/3을 계산하고 `(p′0−p′)/p′0`를 ru로 표시한다. 본 앱은 이 그래프를 그대로 복제하지 않는다. 편차응력과 평균총응력이 변하는 삼축시험에서 위 비율을 수압증가비와 무조건 동일하게 두지 않고, 앞의 응력 열 차이로 구한 u와 초기 실측 구속압을 사용한다. 원문 표의 18회·41회는 출처의 정의와 보고 단위 그대로 인용하며 앱의 8개 점에서 다시 판정하지 않는다.

## 8개 실제 관찰점

시간은 원기록의 값을 표시할 때만 반올림한다. 행 번호는 헤더를 1행으로 센 원파일 번호다. 1분/주기이므로 t/T의 숫자는 t(min)와 같다.

| 관찰점 | 원행 | t(min) | ru, 재계산 | εa(%) | 학습 포인트 |
|---|---:|---:|---:|---:|---|
| 1 | 2 | 0.000 | 0.000 | -0.004624 | 초기 상태와 기준 |
| 2 | 304 | 5.033 | 0.614 | -0.3260 | 수압 축적 |
| 3 | 604 | 10.033 | 0.866 | -0.6081 | 유효구속압 감소 |
| 4 | 1024 | 17.033 | 0.994 | -0.7907 | ru≈1과 아직 작은 축변형 |
| 5 | 1804 | 30.033 | 1.003 | -1.2190 | 반복 진행과 변형 증가 |
| 6 | 2404 | 40.033 | 1.007 | -1.5340 | 거의 0인 유효구속압 |
| 7 | 2417 | 40.250 | 0.781 | +0.4838 | 같은 주기의 압축 위상 |
| 8 | 2449 | 40.783 | 0.196 | -2.5060 | 신장 위상의 큰 변형 |

8개 점은 사건 진행과 서로 다른 재하 위상을 읽기 위해 선택했다. 같은 위상의 균등 간격 표본이나 주기별 최대·평균값이라고 주장하지 않는다. 전체 실측 곡선도 함께 표시해 선택점 사이의 변동을 감추지 않는다. 근접한 6~8번 점의 x 위치가 비슷한 것은 실제 기록시간이 가깝기 때문이다.

점 4와 점 8의 차이가 핵심이다. 수압이 초기 유효구속압에 가까워진 기록 이후에도 변형이 진행되고, 큰 변형이 발생한 순간의 ru가 반드시 1인 것은 아니다. 이 조밀한 모래의 cyclic mobility 기록을 무제한 유동파괴의 예측이나 현장 침하량·측방유동량으로 바꾸지 않는다. 축변형 εa를 전단변형 γ로 간주하지 않는다.

## API와 화면

`CyclicEvidence.read({point: 1~8})`는 `valid`, `errors`, `source`, `reference`, `current`, `observations`, `series`를 반환한다. 정수 외 입력, 범위 밖, null, 누락값은 실패한다. 중간 시각 입력·물성 변경으로 새로운 응답을 만들지 않는다. 공개한 원자료·선택점 객체는 freeze하여 실수로 수정되지 않게 했다.

Lab key는 `cyclic-evidence`, namespace는 `CyclicEvidenceLabs`, `navGroup`은 `mechanics`. 질문 하나, 관찰점 슬라이더 하나다. 이 실험은 실제 자료 읽기이므로 독립적인 물성 슬라이더를 추가하지 않는다. 같은 시료·고정 CSR·시험조건을 항상 명시한다. 두 그래프는 같은 시간축의 ru와 εa이고 선택점·저장한 기준점은 동시에 이동한다. 상세 표에는 행 번호와 자료 내려받기 링크가 있다.

## 검증

- 원파일 SHA-256, 헤더·열수·6,001행, 라이선스 및 DOI 기록 확인.
- 화면의 2,521개 점 모두 실제 원행과 5개 표시 열이 일치함을 확인.
- 8개 선택점과 CSV가 원행·시간·변형·응력에 일치함을 확인.
- 독립 대입: 원행 604에서 u=156.02, Δu=86.36 kPa, ru=86.36/99.74; 원행 2449에서 Δu=19.52 kPa, εa=-2.506%.
- 원행 2404: ru=100.4507/99.74>1이지만 Δσ3=1 kPa를 포함하면 σ′3=0.2893 kPa로 일치.
- 전 표시 행의 총·유효응력 분해, ru와 평균유효응력 감소비의 구별, 기록 불변성, 잘못된 시점 입력, 단일 질문·슬라이더 계약.
- `node --test tests/cyclic-evidence.test.mjs`: 14/14 통과.
- 별도 렌더 확인: 390·768·1440 px에서 관찰점 8개씩 총 24개 조합을 점검했다. 페이지 오류·가로 넘침·비유한 SVG·SVG 글자 잘림·슬라이더와 숫자 값 불일치가 없었다. 모바일·데스크톱 그림도 시각 확인했다.

이 묶음은 기본 반복하중 학습을 제공한다. 자유로운 지진응답 해석·밀도별 인과 비교·CSR 변경 예측·발생 후 현장 변위 추정은 이 한 시료의 자료만으로 완료했다고 표시하지 않는다.
