# 지중응력·전단강도·삼축시험 실험

이 묶음은 계획 영역 08, 11, 12 및 26의 기본 관계를 제공한다. `StrengthStress`는 DOM과 외부 라이브러리에 의존하지 않는 계산 모듈이며, `StrengthStressLabs`는 공통 화면에 등록하는 3개 실험·7개 질문이다. 실무 설계 계산서나 모든 구성모형을 구현한 것으로 보지 않는다.

## 제공 질문과 고정 조건

| 실험·질문 | 함께 바꾸는 입력 | 실제 계산·표시 | 고정 조건·한계 |
|---|---|---|---|
| 지중응력 / 원형 등분포 | Q 또는 q, 반지름 a, 관찰깊이 z, 중심거리 r | 단면 응력증가, 해당 r의 깊이 분포, 관찰점 Δσz, Q·q | 균질·등방 선형탄성 반무한체, 지표 수직 등분포 압력 |
| 지중응력 / 점하중 | Q, z, r | Boussinesq 점하중 응력증가와 깊이곡선 | 이상화한 집중하중이며 작용점은 특이점 |
| 전단강도 / 응력과 파괴 | σ3′, 편차응력 q, c′, φ′, 관찰면 법선각 θ | 같은 척도의 Mohr 원과 파괴포락선, 관찰면 응력, 접하는 파괴원 | 압축 유효주응력, 선형 Mohr–Coulomb |
| 전단강도 / 강성과 강도 | σ3′, q, c′, φ′, 지정 축변형률 εa | 원점–지정점의 할선 Esec, 별도로 정한 파괴저항 qf | 가상 시험 관측점의 해석; 연속 거동을 예측하지 않음 |
| 삼축시험 / UU | 총 구속압 σ3, 측정 q, 관측 파괴 여부 | 전응력원, τmax, 조건을 충족하면 su | 포화 공시체, 구속·전단 모두 비배수, 이 예제는 u 미측정 |
| 삼축시험 / CU + 수압 | σ3, 측정 q, 측정 u, 관측 파괴 여부 | 전응력원과 유효응력원, p′, 조건별 su | 사전 압밀 후 비배수 전단; 수압은 동일 시점의 별도 측정값 |
| 삼축시험 / CD | σ3, 측정 q, 균일 배수 역압 ub | 전응력원과 유효응력원, 전단 과잉수압 0과 전체 u 구별 | 충분히 느린 배수 전단; 전체 u=ub |

Q/q의 유지 조건을 바꾸면 이전 유효 상태의 Q와 q를 동기화해 동일한 물리 상태에서 비교를 시작한다. 그 이후 a를 바꾸어 두 조건의 차이를 관찰한다. Q와 q 입력은 초기 슬라이더 범위를 넘는 직접 입력도 가능하며, 유한한 비음수인지 계산 모듈이 검사한다. 화면의 기하 범위는 a=0.5~3 m, z=0~12 m, r=0~6 m이다. 서로 다른 질문에서 사용하지 않는 입력은 검사 대상에서 제외한다.

## 단위와 정의

- 길이: m. 총하중 Q: kN. 응력·압력·강도: kPa = kN/m².
- 지중응력의 q는 재하압이다. 삼축시험과 전단강도의 q는 σ1−σ3인 편차응력이다. 입력 도움말에 이 차이를 명시한다.
- 압축응력을 양(+)으로 둔다. 삼축압축에서 σ1=σ3+q, σ2=σ3.
- p′=(σ1′+2σ3′)/3은 3차원 평균 유효응력이다. 일부 수정 Mohr 도표의 반합 p 및 반차 q 좌표와 다르다.
- φ′와 θ: °. εa는 입력에서 **%**이며, Esec 계산 전에 100으로 나눈다. Esec 계산값은 kPa, 화면은 MPa다.

## Boussinesq 지중응력

점하중은 다음 식을 사용한다.

```text
R² = r²+z²
Δσz = 3Qz³ / (2πR⁵)
```

Q=0이면 응력증가는 0이다. Q>0에서 z=r=0은 발산하므로 오류를 반환한다. 지표에서 작용점 밖은 0의 표면 극한을 사용한다. 원형 등분포 재하는 점하중의 해를 재하면에 적분한다.

```text
Q = qπa²
Δσz = ∫A 3qz³ / [2π(ρ²+z²)^(5/2)] dA
r=0: Δσz = q{1−[1+(a/z)²]^(-3/2)}
z=0: 원 안 q, 경계 q/2, 원 밖 0
```

편심 관찰점은 관찰점의 지표 투영을 원점으로 한 극좌표에서 반경 방향 적분을 해석적으로 수행한다. 반경 구간 [l,h]의 적분은 영향계수에 대해 `[1+(l/z)²]^(-3/2) − [1+(h/z)²]^(-3/2)` 형태다. 남은 각도 적분은 적응 Simpson으로 계산한다. 원 밖의 관찰점은 접선 광선 끝점의 제곱근 변화를 완화하는 ψ=αsin(t) 변환을 쓴다. 영향계수 절대 오차허용은 10⁻⁹이며, 재귀 깊이 제한 내 수렴하지 않으면 오류를 반환한다. 오차 추정은 엄밀한 수학적 오차 상계의 증명이 아니라 수치적 추정값이다.

단면은 x=−6~6 m, z=0~12 m를 같은 길이 척도로 표시한다. 24×24개 0.5 m 셀의 중심에서 실제 응력증가를 구한다. 관찰점 결과는 격자 보간값이 아닌 이론식의 직접 계산값이다. 깊이곡선은 81개 점이며 점하중 원점의 특이값은 유한한 값으로 바꾸지 않고 제외한다. 색상척도는 0~100 kPa로 고정하여 하중 변화의 크기를 비교할 수 있게 한다. 100 kPa를 넘는 값은 같은 진한색으로 표시하며 이를 그림 범례에 명시한다. 정확한 관찰점과 격자 최대값을 별도로 제공한다. 등색의 상세 형상에는 셀 해상도 한계가 있다.

이 실험은 강체 기초의 실제 접지압 분포, 다층 지반, 소성 파괴, 침하를 계산하지 않는다. Boussinesq 수직응력 식에 E가 없다는 사실은 침하가 E와 무관함을 뜻하지 않는다. 같은 응력증가에 대한 변형은 별도의 강성과 변형모형에 달려 있다.

## Mohr–Coulomb 기하

```text
τf = c′+σ′tanφ′
C = (σ1′+σ3′)/2
R = (σ1′−σ3′)/2
포락선까지 수직 거리 d = c′cosφ′+Csinφ′
σ1f′ = [σ3′(1+sinφ′)+2c′cosφ′]/(1−sinφ′)
qf = σ1f′−σ3′
관찰면: σn′=C+Rcos2θ, τ=Rsin2θ
파괴원의 접점: (Cf−Rf sinφ′, Rf cosφ′)
```

R<d, R=d, R>d를 각각 내부·접함·초과 상태로 구별한다. 초과 입력은 관계 관찰을 위해 결과를 제공하되, 지정 강도와 양립하는 안정 상태나 파괴 이후 거동이라고 표시하지 않는다. 그림의 수직·수평 응력 축은 같은 픽셀/kPa를 사용하므로 원과 접선의 기하를 왜곡하지 않는다. 파괴원은 현재 σ3′를 유지할 때 포락선에 접하는 원이다.

c′·φ′는 시료 상태, 시험조건과 변형수준에 대응해야 한다. 첨두·임계상태·잔류강도를 같은 값으로 바꿔 쓰지 않는다는 설명을 제공한다. 밀도에서 강도정수를 자동 생성하거나 팽창·수축의 전체 구성모형을 예측하는 기능은 포함하지 않는다.

## 강성은 지정 시험점의 해석

```text
εa,fraction = εa,% / 100
Esec = q / εa,fraction
```

이 그림은 가상 관측 한 점과 원점의 할선이다. 전체 응력–변형률 곡선, 실제 초기 접선강성 또는 파괴 이후 연화를 생성하지 않는다. c′·φ′·σ3′로 계산한 qf와 Esec는 서로 다른 정보를 표현한다. 지정점이 qf를 넘으면 강도모형과 양립 여부를 별도로 경고한다. 이미 제공하는 얕은기초 E–침하 실험의 E는 별도로 정한 탄성모형 입력이며, 여기의 한 점 할선계수와 무조건 동일시하지 않는다.

## UU·CU·CD의 계산 범위

모든 시험에서 같은 시점의 σ3와 보정된 편차응력 q를 입력한다. 공시체 면적·장치·막 효과를 보정하지 않은 원시 하중에서 q를 만드는 시험 데이터 처리까지 포함하지 않는다.

- UU: u를 모르는 상태 그대로 남긴다. u=0을 가정하지 않으며 σ1′·σ3′·p′를 생성하지 않는다.
- CU: 측정 전체 수압 u로 σ′=σ−u를 계산한다. 수압의 부호가 변해도 원의 반지름과 편차응력은 변하지 않는다. 포화 상태 및 압력 기준의 일관성은 시험값 해석의 조건이다.
- CD: 전단 과잉수압≈0과 전체 간극수압=0을 구별한다. 이 예제에서는 균일 배수 경계 역압 ub가 전체 u다.
- 관측점이 파괴 시점이라고 명시한 포화 UU/CU에서만 su=qf/2를 제공한다. CU의 값은 그 압밀응력·이력에서의 조건별 비배수강도이며, CU 전응력 포락선을 현장 일반 강도정수로 취급하지 않는다. CD의 τmax는 비배수강도로 이름을 바꾸지 않는다.
- u>σ3이면 유효 최소주응력이 인장이므로 현재의 포화 압축 모형 밖으로 처리한다. UU에는 사용하지 않는 u·ub 오류를 전파하지 않는다.

원 사이의 표시는 같은 시점의 좌표 변환이다. 시간에 따른 응력경로나 수압 발생량을 예측한 것이 아니다. 한 시험점으로 c′와 φ′를 동시에 구할 수 없다. Skempton A·B, 비선형 구성모형, 연속 실측 경로, 비등방 압밀 및 잔류강도 시험의 상세 구현은 별도 범위다.

## 검증

`tests/strength-stress.test.mjs`의 31개 검사가 통과했다. 다음을 확인한다.

- 점하중 수계산, 하중 선형성, 길이의 역제곱 척도, 무재하 및 표면·특이점 처리.
- 원형 중심 폐형식, z=a의 영향계수 `1−2^(−3/2)`, 기하학적 상사, 압력 선형성.
- 편심 3개 위치에서 독립적인 하중중심 극좌표 2차원 중점 면적적분(240×720점)과 상대오차 2×10⁻⁵ 이내 비교.
- 원형의 내부·경계·외부 표면 극한 및 z=10⁻⁴ m 근접값, 먼 거리에서 동등 점하중 해로 수렴.
- Q 고정과 q 고정의 반지름 2배 비교, 직접 관찰점과 격자의 구분.
- c′=0, φ′=30°, σ3′=100 kPa, q=200 kPa의 수계산 및 φ′ 0~60° 접점 기하·거리 일치.
- 관찰면 회전의 원 반지름 불변량, φ′=0에서 qf=2c′, 포락선 초과 상태.
- εa=0.5%, q=120 kPa일 때 Esec=24 MPa, 변형률을 2배로 할 때 할선은 절반이고 qf는 불변.
- CU 전·유효응력 변환, 반지름·q 불변량, CD의 0 과잉수압과 비영 역압, UU의 미측정 수압 보존.
- 유한값·압축 범위·모드·활성 입력 검증.

공통 셸을 결합한 별도 Playwright 점검에서 3개 실험·7개 질문의 기본 렌더링, 각 질문의 비활성 필드 오류 차단 여부, Q↔q 전환 후 결과 보존, 390 px 모바일 가로 넘침 및 브라우저 오류를 확인했다. 그림은 1440 px 및 390 px에서 직접 검토했다. 이는 개발자 계산·표현 검증이며 사용자 학습효과 검증을 대신하지 않는다.
