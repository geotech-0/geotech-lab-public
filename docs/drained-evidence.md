# 실제 배수전단 기록 비교

범위: 같은 Karlsruhe fine sand의 느슨한 TMD2와 조밀한 TMD22를 실제 제공 기록에서 비교한다. 전단강도 이론 실험의 c′·φ′ 입력 및 강성 계산에 연결되는 **자료 읽기 실험**이다. 밀도 슬라이더가 예측 곡선을 만들지 않는다.

## 등록과 API

- 엔진: `src/drained-evidence.mjs`, namespace `DrainedEvidence`.
- descriptor: `src/labs/drained-evidence-lab.js`, `DrainedEvidenceLabs` 한 항목.
- key `drained-evidence`, navGroup `mechanics`, meta `kind:'data'`, `displayOnly:true`.
- 두 보기: `strain`은 같은 x축의 q–εa와 εv–εa, `path`는 q–p′. 질문 상태만 바꾸며 데이터와 커서는 유지한다. 공통 앱의 displayOnly 처리로 중복 질문 탭을 만들지 않는다.
- `DrainedEvidence.read({strain:6.2})`: 기본값 6.2%, 0–20%, 0.1% 간격. `valid`, `errors`, `strain`, `index`, `samples`, `loose`, `dense`, `source` 반환. 6.25% 같은 미기록 값은 보간하지 않고 오류를 반환한다.
- `tests`: 읽기 전용 두 시험. `records`의 각 점은 `index,strain,volumeStrain,sigmaR,sigmaV,q,p,maxShear`를 가진다. `first,last,peak,peakInterior,maxContraction,finalOnePercentVolumeChange`와 고정 초기 상태도 제공한다.
- `read().samples`는 `current,previous,volumeIncrement`를 추가한다. `volumeIncrement`는 직전 0.1% 기록과의 %p 차이다. index=0이면 null이다.
- `source`, `bounds`도 읽기 전용이다. 모든 402점을 내장하여 외부 요청 없이 동작한다.

## 보이는 학습 내용

같은 축변형률에서 q·p′·최대 전단응력·εv를 두 열로 비교한다. 화면에 현재 응력 수치로 대입한 q 및 p′ 식이 항상 보인다. q가 τ 자체가 아님과 3D 평균 p′가 Mohr 원 중심과 다름을 명시한다.

누적 체적변형률의 부호와 최근 변화 방향은 다르다. 느슨한 시험은 7.5%에서 최대 압축 εv=+1.2475% 후 팽창 방향으로 움직이지만 20%에서도 εv=+0.6815%다. 조밀한 시험은 초기에 조금 압축한 뒤 큰 팽창을 보인다. ‘느슨=끝까지 수축’ 또는 ‘조밀=처음부터 팽창’이라는 합성 도식으로 바꾸지 않았다.

q–p′ 경로는 실제 응력 열로 계산한다. 거의 일정한 방사응력에서는 q=3(p′−σr′)이므로 경로가 가깝거나 겹치는 것이 정상이다. 표시만 다르게 하고 경로를 임의로 벌리지 않는다. 두 기록의 q–εa·εv–εa 반응은 다르다.

기록 내 최대와 관측 종점, 임계상태, 잔류강도를 구분하는 설명을 기본 이론 영역에 둔다. 자료 끝에 도달했다고 임계·잔류로 분류하지 않는다. 기준값 비교를 켜면 기존 커서의 실제 기록점·선만 회색으로 표시한다.

## 계산·출처

`q=σv′−σr′`, `p′=(σv′+2σr′)/3`, `τmax=|q|/2`. 입력 응력은 kPa, 변형률은 %, 압축 양수다. 작은 초기 음의 q 및 방사응력 변화도 그대로 보존한다. 매 행의 응력을 쓰고 공칭 100 kPa로 치환하지 않는다.

[데이터 가공·인용·라이선스 기록](../assets/data/drained-provenance.md)에 원 실험 논문, 4TU 공개 편찬본 v3, CC BY 4.0, 원·선택 CSV SHA-256 및 변경 내역을 기록했다. 이 자료는 원시 계측 로그가 아니다. 편찬 README는 대부분 디지타이즈·반올림을 거친다고 명시하므로 화면에서도 이를 밝힌다. 원 논문의 모형 계산 곡선은 사용하지 않는다.

원 논문 §3.2, Table 3, Fig.4에서 시험 조건을 확인했다. 공중낙사 성형, 기본 d≈h≈100 mm, 윤활 단판, 등방압밀, 축변위속도 0.1 mm/min. 해당 절에 독립적으로 명시되지 않은 포화도·배압은 추가하지 않았다.

## 검증 범위

`node --test tests/drained-evidence.test.mjs`의 독립 검증 23개가 통과했다. 선택 402점과 내장 값의 일치, 파일 해시, 0.1% 격자, 단위·부호, 손계산 q/p′/τ, 유효 방사응력 드리프트 보존, 내부 첨두와 종료점 최대 구별, 초기·마지막 체적변화 및 경계 입력을 확인했다. 두 그래프 모두 전체 201개 커서와 기준값에 대해 유한한 SVG를 반환한다.

등록 전 임시 앱을 구성한 Chrome 점검에서 1440 px·390 px의 두 보기를 캡처하고 시각 검토했다. 가로 넘침 0, 페이지 오류 0, 모바일 그래프 영역 높이 약 331 px, 기록 커서 1개다. 6.2%와 20% 실제 입력, 보기 간 값 유지, 미기록 6.25% 오류와 복구, 기준 기록점 표시를 확인했다.

등록 후 실제 제공 앱에서도 1440 px·390 px를 독립 점검했다. 공통 그림탭 DOM을 재사용하도록 수정한 이후, 숫자 직접 편집 직후 첫 탭 클릭이 정상적으로 전환되고 커서가 유지됨을 확인했다. 20%를 기준으로 저장한 뒤 현재 6.2%를 읽는 비교, 6.25% 오류 뒤 복구, 그래프 확대·Escape 종료·실행 버튼으로의 포커스 복귀가 모두 통과했다. 같은 감사에서 기초 Q/q 모드 전환과 용어 도움의 키보드 접근, 다짐 자료 전환의 비활성 오류 분리·비교 모형 구분도 확인했다. 실제 제공 앱의 가로 넘침과 브라우저 오류는 없었다.

## 남은 범위

이 화면은 첨두·체적변화·응력경로를 읽는 한 재료의 두 실험이다. 전체 전단 거동을 완성했다고 보지 않는다. 추가 구속압·중간 밀도·다른 재료의 관측 선택, 대변형 잔류/링전단 자료, 독립적으로 확인한 임계상태선, 일반 응력경로 제어, 전단대 국소변형, 구성모형 예측은 별도 검증과 자료가 필요하다. 편찬 수치의 소수 자리 수를 계측 정확도로 해석하지 않는다.
