# 좌우 지반 차이와 강체 기초의 변형 적합

`foundation-compatibility`는 기초형식의 기본 차이를 보기 위한 제한된 모형이다. 길이 1 m의 띠기초를 좌우 반폭씩 다른 선형 Winkler 스프링 위에 놓고, 같은 중심 총하중에서 독립 스프링의 균등압력 조건과 무중량 강체판의 회전 자유 조건을 비교한다. 실제 독립기초와 전면기초의 설계를 서로 대체하지 않는다.

## 단위·유도

폭 B는 m, 평균 재하압 q는 kPa, 지반계수 k는 kN/m³이다. 화면의 MN/m³ 입력은 1000을 곱한다. 길이 1 m당 하중 Q=qB의 단위는 kN/m다. x는 중심을 0으로 한다. 하향 침하 w가 양수다.

강체판은 w(x)=w₀+θx이고, 스프링은 q(x)=k(x)w(x)다. 연직 힘 ∫qdx=Q와 중심 모멘트 ∫xqdx=0을 만족시킨다.

```
A0=(kL+kR)B/2
A1=(kR−kL)B²/8
A2=(kL+kR)B³/24
[A0 A1; A1 A2] [w0; θ] = [Q; 0]
```

독립 스프링은 각각 wL=q/kL, wR=q/kR이다. 비교 결과의 ‘좌우 반폭 중심의 차’는 같은 x=−B/4와 +B/4 두 위치의 이동 차이다. 강체판에서는 θB/2, 독립 스프링에서는 wR−wL다. 기초 회전은 강체 기울기이며 구조물의 균열 허용 각변형으로 판정하지 않는다.

기본 B=4, q=100, kL=5000, kR=15000이면 w₀=12.30769 mm, θ=−4.61538 mrad, 좌우 가장자리 침하 21.53846/3.07692 mm다. 독립 스프링은 20/6.66667 mm다. 강체판의 전체 평균 침하가 작아져도 일부 위치의 침하가 독립 조건보다 커질 수 있다.

계수 비 5에서 한쪽 가장자리 접지압이 0이고, 5를 넘으면 전면접촉 해에 인장 반력이 나타난다. 현재 UI는 그 조건을 오류로 설명하고 부분접촉을 임의로 잘라 붙이지 않는다.

## 근거와 한계

[FHWA NHI-05-037 §5.4.6](https://www.fhwa.dot.gov/engineering/geotech/pubs/05037/05c.cfm)의 Winkler 지지 개념과 k의 크기·강성 의존성 설명을 참고한다. 위 두 구간 해는 적합·평형조건에서 직접 유도했다. FHWA의 경험식이나 실제 전면기초 설계식을 그대로 구현한 것으로 표시하지 않는다.

이 모형에서는 지반 스프링 사이 연속체 전단전달이 없다. 구간 경계의 침하는 강체 조건에서 연속이지만 압력은 불연속이다. 고정 q·k에서 폭만 바꿀 때 평균 침하가 변하지 않는 것은 현재 모형의 특징이지 실제 지반 크기 효과가 없다는 뜻이 아니다. 기초의 유한 휨강성·부분접촉·소성·3D 응력확산·압밀·깊이별 변화·구조물 회전구속은 제외한다.

## 검증

9개 모델 검사: 균질 손계산, 두 지반 손계산, 독립 10,000점 적분에 의한 힘·모멘트 평형, 변형 적합, 좌우 교환 대칭, 하중·강성·폭 비례, 무재하, 접촉경계, 부적합 입력 거부. 브라우저 검증은 공통 통합 검증에 포함한다.
