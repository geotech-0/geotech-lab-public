# 복합지반 하중분담

`composite-ground`는 같은 두께의 원지반과 개량부를 강판으로 함께 압축할 때, 면적의 비율과 하중의 비율이 달라지는 이유를 보여주는 한 질문 실험이다. 입력 5개는 개량 면적비·원지반 구속계수·개량부 구속계수·평균 증가응력·층두께다. 수치 계산은 정역학적 평형과 같은 수직변형률의 적합조건으로 닫힌다.

기본값에서 개량부 면적은 20%지만 하중의 71.4%를 받는다. 두 영역의 공통 침하는 57.14 mm이며, 같은 하중·두께·원지반 물성의 미개량 침하 160 mm와 비교한다. 이 값은 입력된 탄성 물성으로 계산한 이상화의 결과이며 현장 개선효과의 예측값이나 권장 물성이 아니다.

## 제공 범위와 모형

- 높이 H로 같은 두 탄성 영역, 공통 강판, 각 영역의 횡변형 구속.
- 완전 배수 상태에서 추가한 평균 수직응력 q.
- 동일 수직변형률 ε, 공통 침하, 각각의 증가응력과 총 하중 몫.
- 면적비 a=0·1 및 두 재료 강성이 같은 경우의 극한.
- 더 부드러운 재료로 대체했을 때 침하가 증가하는 역방향 비교.

두 물성은 모두 **구속계수 M=1/mv**이고 단위는 kPa다. Young 계수 E를 입력한다고 가정하지 않는다. 실제 기둥의 횡팽창·주변지반과의 전단전달·응력집중비 변화까지 표현하는 모형이 아니다. 면적비만으로 실제 기둥 직경·배치·간격을 결정하지도 않는다.

아칭, 지오신세틱 보강, 하중전달층, 말뚝 선단·주면, 하부 미개량층의 침하, 기둥 팽창·전단파괴, 극한지지력, 배수속도·압밀시간·시공 효과는 구현하지 않았다. 계산된 개량부 응력을 기둥의 안전성이나 재료강도와 자동 비교하지 않는다. 영역 22의 개량·보강 전체를 완료한 것으로 보지 않는다.

## API와 단위

`src/composite-ground.mjs`의 `CompositeGround`는 import와 외부 의존성이 없는 namespace다.

```js
CompositeGround.solve({
  areaRatio: 0.2,       // 0~1, 전체 면적 중 개량부 비율
  soilModulus: 5000,    // kPa, 원지반 구속계수 Ms
  columnModulus: 50000, // kPa, 개량부 구속계수 Mc
  deltaStress: 100,    // kPa, 전체 평균 증가응력 q
  thickness: 8         // m, 공통 층두께 H
})
```

면적비는 0~1, 두 계수·층두께는 양수, 증가응력은 0 이상이어야 한다. 비유한 입력 또는 계산량은 `{valid:false, errors:[...]}`로 거절한다. 유효 결과는 `{valid:true, errors:[], ...}`다. UI 범위는 a=0~1, Ms=2~50 MPa, Mc=2~200 MPa, q=0~200 kPa, H=1~20 m다. 물성 입력은 MPa로 표시하고 엔진에 kPa로 저장한다.

주요 출력:

| 필드 | 의미·단위 |
|---|---|
| `referenceArea` | 1 m² |
| `equivalentModulus`, `modulusRatio` | Meq(kPa), Mc/Ms |
| `strain`, `settlementMm` | 공통 변형률, 공통 침하(mm) |
| `soilStress`, `columnStress` | 각 영역의 증가응력(kPa); 영역이 없으면 null |
| `soilLoad`, `columnLoad`, `totalLoad` | 기준 면적 1 m²에서의 힘(kN) |
| `soilLoadFraction`, `columnLoadFraction` | 실제 하중분담 비율; 무재하이면 null |
| `columnStiffnessFraction` | aMc/Meq; 무재하에서도 정의되는 강성 몫 |
| `stressConcentration` | σc/σs; 양쪽 영역과 재하가 모두 있을 때만 정의 |
| `untreatedSettlementMm`, `reductionMm` | 미개량 침하 및 미개량−복합 침하(mm) |
| `settlementRatio` | S/S₀; 무재하에서는 null |
| `forceResidual`, `compatibilityResidual` | 수직 힘 평형 및 변형률 적합 잔차 |
| `smallStrainExceeded` | 공통 또는 미개량 변형률이 0.1 초과인지 표시 |

`smallStrainExceeded`는 선형 외삽을 드러내기 위한 기술 플래그이며 설계 허용값이 아니다. UI 범위에서는 두 변형률 모두 0.1 이하다. 양의 유한 수를 받는 순수 엔진이 큰 변형률까지 물리적으로 검증되었다는 뜻이 아니다.

## 식과 독립 유도

기준 면적 A=1 m²에서 개량부 면적은 aA, 원지반 면적은 (1−a)A다. 두 영역이 같은 H를 가지며 같은 강판 변위 S를 받는다.

```
εc = εs = ε = S/H
σc = Mc ε
σs = Ms ε
qA = σc aA + σs (1−a)A

Meq = aMc + (1−a)Ms
ε = q/Meq
S = qH/Meq
```

단위는 `(kPa)·m/(kPa)=m`이고 화면 침하는 1000을 곱해 mm로 표시한다. 하중이 있을 때 개량부 몫은 `Qc/Q = aMc/Meq`, 원지반 몫은 `(1−a)Ms/Meq`다. 양쪽 영역이 존재하고 하중이 있으면 `n=σc/σs=Mc/Ms`다.

```
S₀ = qH/Ms
S/S₀ = Ms/Meq = 1/[1+a(n−1)]
```

이 식의 n은 본 선형·구속 변형 가정에서 유도한 값이다. 실무 기둥의 응력집중비를 그 강성비로 자동 대체하는 일반 법칙으로 적용하지 않는다. 면적을 늘리면 개량부의 총 분담 하중은 늘면서 개량부 단위면적당 응력은 감소할 수 있다. 그래서 응력과 하중 몫을 구분해 표시한다.

## 화면 계약

`CompositeGroundLabs`는 `key:'composite-ground'`, `navGroup:'practice'`, 질문 `sharing` 하나를 제공한다. 계산을 재사용한 중복 탭이 없다. 다섯 슬라이더를 한 번에 보여주고 상세 가정·식·출처는 기존 공통 설명 영역을 쓴다.

한 SVG에서 왼쪽은 같은 변위의 두 영역, 오른쪽은 면적 몫과 하중 몫의 두 막대다. 왼쪽 폭은 면적비를 표현하며 실제 기둥 배치 단면이 아니다. 변형 확대배율을 표시한다. 짧은 점선은 초기 높이, 긴 점선은 현재 Ms·q·H로 계산한 미개량 침하 높이다. 이 점선은 저장 조건이 아니며 `comparisonPlot:false`다. 저장 조건은 기존 결과 수치 비교로만 전달한다.

무재하에서는 하중 화살표와 실하중 비율을 그리지 않는다. 없는 영역의 응력은 ‘영역 없음’으로 표시한다. Mc<Ms이면 ‘침하 감소’ 결과가 음수가 되고, 설명에서도 침하 증가임을 밝힌다. 두 재료 강성이 같으면 면적을 바꿔도 침하가 같고 하중 몫은 면적 몫과 같아진다.

연직드레인 실험과의 연결은 한 문장으로 제공한다. 이상화한 드레인은 압밀의 시간경로를 바꾸는 반면, 여기서는 배수 완료 후의 복합강성을 바꾸어 최종 압축량을 비교한다. 실제 개량공법이 두 효과를 동시에 낼 수 있다는 사실을 부정하거나 동일한 기능이라고 취급하지 않는다.

## 검증

`node --test tests/composite-ground.test.mjs`의 13개 테스트가 다음을 확인한다.

1. 독립 손계산: a=.25, Ms=10000, Mc=30000 kPa, q=120 kPa, H=10 m → Meq=15000 kPa, ε=.008, S=80 mm, σs=80 kPa, σc=240 kPa, Qs=Qc=60 kN, 미개량 S₀=120 mm.
2. a=0은 원지반 단일층, a=1은 개량재 단일층으로 돌아가며 존재하지 않는 영역의 응력은 null.
3. Mc=Ms이면 면적비와 관계없이 침하 일정, 하중 몫=면적 몫.
4. 응력집중비와 하중분담 비율의 수치적 구분.
5. UI 계수·응력 양 끝과 면적비 5개를 조합한 40조건의 힘 평형과 변형률 적합, Meq의 상·하한.
6. 두께 2배이면 침하만 2배, 하중 2배이면 침하·응력·힘 2배이고 하중 몫 일정.
7. 단단한 개량부의 면적 증가에 따라 침하 감소·총 하중 몫 증가·단위면적당 개량부 응력 감소.
8. 부드러운 대체재는 침하 증가를 허용하며 개선으로 잘못 판정하지 않음.
9. 무재하의 0 응력·침하 및 비율의 미정의 처리.
10. 독립 병렬 스프링 `ks=(1−a)Ms/H`, `kc=aMc/H`의 힘−변위와 변형에너지 대조.
11. 음수·범위 초과·NaN·수치 표현 불가 입력의 거절 및 큰 선형 변형률 플래그.

기본 화면을 실제 앱 CSS로 렌더하고 390px에서 가로 넘침이 없는지 확인했다. 추가 경계 렌더는 무재하·면적비 양 끝·같은 강성·부드러운 대체재에서 비유한 숫자나 미정의 문자열 없이 생성되는지 확인한다.

## 원출처와 적용 범위

- [FHWA NHI-16-027, Ground Modification Methods Reference Manual, Volume I](https://www.fhwa.dot.gov/engineering/geotech/pubs/nhi16027.pdf), 제5장 §4.1.2, 인쇄 p.5-31–32, 식 5-1~5-5: 개량 면적비, 응력집중비, 전체 수직 평형, 각 영역 응력의 관계를 공식 PDF 원문과 대조했다. 현장 응력집중비는 변형·시간·구속 등에 영향을 받으므로 본 실험의 n=Mc/Ms를 실무 기본값으로 확대하지 않는다.
- [Castro & Sagaseta (2010), Discussion of “Simplified Plane-Strain Modeling of Stone-Column Reinforced Ground”](https://doi.org/10.1061/(ASCE)GT.1943-5606.0000339), Journal of Geotechnical and Geoenvironmental Engineering 136(6), 892–894, “Basic Ideas”의 confined-modulus 관계: 원 출판사 본문에서 횡변형을 구속한 같은 변형률의 평균 강성 `aMc+(1−a)Ms`와 평형·적합조건을 확인했다. 이어지는 방사방향 변형을 허용한 확장은 본 실험에 포함하지 않는다.
- [FHWA-HRT-13-046, Chapter 6, §6.1.5](https://www.fhwa.dot.gov/publications/research/infrastructure/structures/bridge/13046/006.cfm), 그림 46·47: 심층혼합의 복합강성과 침하 절차를 대조했다. 이 문헌은 기둥의 횡구속이 작다는 가정으로 `aEdm+(1−a)Msoil`를 사용한다. 따라서 두 재료에 구속계수를 쓰는 본 학습 이상화와 계수의 의미가 다르며, FHWA의 실무 절차를 그대로 구현했다고 표시하지 않는다.

국내 기준의 하중 조합·허용치·시공 품질·시험 물성 선정은 이 실험에 들어 있지 않다. 다음 실무 계산서 단계에서 실제 공법과 재료 모델을 정한 뒤 별도로 다룰 범위다.
