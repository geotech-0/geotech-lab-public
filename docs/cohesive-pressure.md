# 점착성 토압과 인장균열

기존 `earth-pressure` 메뉴의 `cohesive` 질문이다. 건조·균질 c′–φ′ 토사, 수평 배면, 매끈한 수직벽의 Rankine 주동 상태를 대상으로 한다. H, φ′, γ, q, c′를 함께 조작하며 원식의 인장 요구와 인장을 받지 않는 접촉압을 구분한다.

## 근거와 구현 범위

[Caltrans Trenching and Shoring Manual, Chapter 4, July 2025](https://dot.ca.gov/-/media/dot-media/programs/engineering/documents/structureconstruction/ts/ts-chpt-4-a11y.pdf), 인쇄 pp.4-18–4-21 (PDF pp.19–22)를 2026-09-22 확인했다. Eq.4-4-4의 σv에 γz+q를 대입한다. q=0이면 Eq.4-4-10과 균열 깊이 Eq.4-4-13으로 돌아간다. 원문 Eq.4-4-11은 원식 전체를 부호 있게 적분한 값이다.

원문의 p.4-20은 이후 실제 흙막이의 수정 겉보기 토압과 최소계수 절차를 설명한다. 본 화면은 그 설계 절차를 구현한 것이 아니다. **명시적인 인장 접촉 0 가정에 따른 기본 역학 관계**를 보여준다. 수압을 고려하지 않는 건조 상태에서 c′·φ′는 배수 전단강도 정수로 취급한다. 비배수 su, 불포화 흡수력 또는 현장 균열을 자동 역산하지 않는다.

## 계산

- `Ka = (1−sinφ′)/(1+sinφ′)`
- `p_raw(z) = Ka(γz+q)−2c′√Ka`
- `p_contact(z) = max(0,p_raw(z))`
- `z0 = (2c′/√Ka−q)/γ` (원식의 부호 있는 영점)
- `potentialCrackDepth = max(0,z0)`
- `zc = min(H,potentialCrackDepth)` (벽 범위의 이론 비접촉 깊이)
- `P = ∫₀ᴴ p_contact dz`, `M_base = ∫₀ᴴ p_contact(H−z) dz`
- `yR = M_base/P`, 단 `P=0`이면 `null`

양압 구간 길이 L=H−zc, 상단·하단 압력을 p0,p1이라 하면 정확한 사다리꼴 적분은 `P=L(p0+p1)/2`, `M_base=L²(2p0+p1)/6`이다. 부분 접촉이면 p0=0이므로 작용높이는 (H−zc)/3. 상부부터 압축을 받는 사다리꼴에서는 H/3으로 고정하지 않는다.

압력은 kPa, 힘은 단위 벽 길이당 kN/m, 모멘트는 kN·m/m이다. 원식의 음수 면적을 P에서 빼지 않는다. 전 높이가 비접촉인 경우 결과 0과 미정의 작용점을 명시하고 자립 안정·무지보 굴착 판정으로 해석하지 않는다.

## 화면과 상태

- 질문 id: `cohesive`, 신규 상태: `cohesion=12 kPa`, UI 범위 0–60 kPa.
- 활성 입력: `height`, `phi`, `gamma`, `surcharge`, `cohesion`.
- 다른 질문의 `waterDepth`, `gammaSat`, `state`, `ocr`, `delta`, `beta`는 보이지 않고 계산에서 제외한다.
- 현재 원식 인장부는 주황 점선, 압축 접촉은 청록 실선·면적. 비교 기준은 공통 압력·깊이 축 위의 회색 점선으로 실제 계산하여 그린다.
- 균열 틈의 폭은 가독성을 위해 과장한 표시이고 실제 균열 폭·위치·발생 시점 예측이 아니다.

## 장기 강도와 물

Caltrans p.4-18은 수축·팽창, 습윤·건조, 포화도와 균열로 점착성 토압 평가가 달라질 수 있음을 설명한다. c′를 줄일 때 결과가 바뀌는 관계는 계산하지만 시간에 따른 c′ 저하나 장기 잔존량을 예측하지 않는다. p.4-21의 균열수압 필요성도 설명한다. 균열에 물을 임의로 추가하고 하부 간극수압 경계를 생략하는 혼합을 피하기 위해 이번 질문은 건조 상태만 지원한다. 물 토압은 기존 c′=0 질문으로 연결한다.

## 검증
