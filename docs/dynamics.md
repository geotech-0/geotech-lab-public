# 동적 거동·액상화 입문

계획 영역 23·26 중 파속, 작은 변형 강성, 기본주기, 지정 강성저하 및 단순화 액상화 수요·저항 관계를 다룬다. 2개 실험과 실제 계산이 다른 3개 질문을 제공한다. 지반의 동적 거동 또는 액상화 전 분야가 완료되었다는 의미는 아니다.

| 실험·질문 | 동시에 보이는 입력 | 실제 계산·그림 |
|---|---|---|
| 파속·동적 강성 / 파속과 기본주기 | Vs, 질량밀도 ρ, 층두께 H | Gmax, T0, f0, 정규화 1차 모드와 T0–Vs 관계 |
| 파속·동적 강성 / 변형수준과 강성 | Vs, ρ, γ, 지정 γr | 쌍곡모형의 Gsec, G/Gmax, τ, 로그 변형률 축의 강성저하 곡선 |
| 액상화 수요·저항 | amax/g, σv, σv′, rd, 기준 CRR | CSR, 보정 CRR, 조건부 저항/수요, 가속도별 수요선 |

액상화의 MSF·Kσ는 상세 입력이지만 현재 채택값은 조건칩, 상세 요약, 기본 이론 대입식에 표시한다. CRR은 기준 규모·상재압이 명시된 가상 지정값이다. 시험·조사 자료 없이 자동 추정한 토질정수가 아니다.

## API와 단위

`src/dynamics.mjs`의 순수 namespace `Dynamics`를 `src/labs/dynamics-labs.js`의 `DynamicsLabs`가 사용한다. 런타임 외부 라이브러리나 네트워크 요청은 없다.

- `smallStrain({velocity,density})`: Vs→Gmax, 질량밀도→단위중량.
- `layer({velocity,density,thickness})`: 자유 지표·고정 기저 균질 전단층의 주기와 모드.
- `reduction({velocity,density,strain,referenceStrain})`: 지정 단순 쌍곡모형의 할선·접선강성과 응력.
- `dynamicLayer(data,question)`: `waves` 또는 `strain`에 필요한 입력만 사용한다.
- `liquefaction({acceleration,total,effective,rd,crr,msf,ksigma})`: 지정 정수의 단순화 수요·저항 비교.

기본 단위는 m, s, kg, kPa다. `velocity`는 m/s, `density`는 kg/m³이다. `gmax`, `gsec`, `gtangent`, `shearStress`는 **kPa로 반환**하며 강성 카드는 MPa로 표시한다. `strain`, `referenceStrain` 입력은 **%**다. 응력 계산에서 100으로 나누고, 두 변형률의 비에는 동일 단위가 상쇄된다. `acceleration`은 amax/g의 무차원 비다. 0.25는 가속도 0.25g를 뜻한다. CSR, CRR, MSF, Kσ, rd는 무차원이다.

## 파속·강성과 1/4 파장

```text
Gmax = ρ Vs²                         [Pa → /1000 → kPa]
γt = ρg                             [N/m³ → /1000 → kN/m³]
T0 = 4H/Vs, f0 = Vs/(4H), λ0 = 4H
φ(z) = cos(πz/(2H)), 0≤z≤H
```

균질 1차원 전단층에서 z는 지표로부터 아래 방향이다. 자유 지표의 전단응력은 0이므로 φ′(0)=0이고, 고정 기저의 변위는 0이므로 φ(H)=0이다. 지표 모드값을 1로 정규화했다. 이 값은 실제 1 m 변위나 1배 가속도 증폭이 아니다.

Vs=200 m/s, ρ=1800 kg/m³, H=20 m이면 Gmax=72 MPa, γt=17.65197 kN/m³, T0=0.4 s, f0=2.5 Hz다. Vs만 2배로 하면 Gmax는 4배, T0는 절반이다. Vs를 고정한 채 밀도만 바꾸면 강성은 달라지지만 이 모형의 주기는 같다. H를 2배로 하면 주기도 2배다.

근거는 [FHWA NHI-16-072 §8.2, Eqs.(8.1)·(8.4), Fig.8-2](https://www.fhwa.dot.gov/engineering/geotech/pubs/nhi16072.pdf) 및 [USGS OFR 99-142의 Karkee, Sugimura & Fujiwara, p.3-7](https://pubs.usgs.gov/of/1999/0142/report.pdf)이다. 후자의 파속·층두께 관계만 참고하고 논문의 지반주기 연장계수, 실제 지진변위, 말뚝 관성·운동학적 상호작용식은 적용하지 않는다. 모드는 위 경계조건의 전단파 방정식에서 계산한다.

기본주기만으로 공진 증폭률을 결정할 수 없다. 입력운동, 감쇠, 기저와 토층의 임피던스 차이, 다층 구조 및 비선형성을 해석하지 않으므로 증폭 그래프를 만들지 않는다.

## 지정 강성저하 모형

```text
Gsec/Gmax = 1/(1+γ/γr)
τ = Gsec γ                          [γ는 이 식에서 소수 비율]
Gtan = dτ/dγ = Gmax/(1+γ/γr)²
τ∞ = Gmax γr
```

[Yoshida & Wakamatsu (2012), Eq.(1a), p.458](https://www.kiso.co.jp/yoshida/yoshida/publish/P12-14.pdf)에 명시된 단순 쌍곡형 강성저하 관계를 사용한다. 이 논문에 있는 토질별 회귀계수와 감쇠식은 사용하지 않았다. γr는 토질·구속압·소성지수에서 만들어낸 값이 아니라 사용자가 지정한 교육용 모형 정수다.

기본값 γ=γr=0.05%에서 G/Gmax=0.5, Gsec=36 MPa, Gtan=18 MPa, τ=18 kPa다. 강성저하 곡선의 x축은 0.0001~1% 로그 축이다. 숫자 입력은 실제 %이며 로그값 자체를 입력하지 않는다. 엔진은 γ=0 극한도 정확히 처리하지만 로그 그래프의 UI는 양의 변형률로 한정한다.

이 모형은 τ∞=Gmaxγr라는 자체 점근값을 만든다. 이를 별도 시험한 c′·φ′·su와 일치하도록 보정하지 않았으므로 실제 지반의 전단강도라고 부르지 않는다. 감쇠·반복이력·시간 의존성·누적변형·과잉수압 발생은 계산하지 않는다.

## 액상화의 제한된 수요·저항 비교

```text
CSR = 0.65(amax/g)(σv/σv′)rd
τavg = 0.65(amax/g)σv rd
CRRcurrent = CRR7.5,1atm × MSF × Kσ
조건부 저항/수요 = CRRcurrent/CSR
초기 간극수압 u0 = σv−σv′
```

CSR 식은 [FHWA-NHI-15-004 (2014), Eq.(3-1), p.3-15](https://www.fhwa.dot.gov/bridge/seismic/nhi130093.pdf)를 따른다. URL 파일명은 `nhi130093.pdf`지만 문서 자체의 보고서 번호는 FHWA-NHI-15-004다. 기준 CRR와 보정 방향은 [Boulanger & Idriss (2014), UCD/CGM-14/01, §§2.1–2.2, Eqs.(2.6)–(2.7)](https://faculty.engineering.ucdavis.edu/boulanger/wp-content/uploads/sites/71/2014/09/Boulanger_Idriss_CPT_and_SPT_Liq_triggering_CGM-14-01_20141.pdf)를 확인했다.

기준 CRR은 M=7.5, 유효 상재압 1 atm 조건이다. CRR·MSF·Kσ·rd는 동일한 평가 체계에서 채택해야 한다. 이미 현재 규모·상재압으로 보정된 저항에 MSF·Kσ를 다시 곱하면 이중 보정이다. 지반이 수평이고 초기 정적 전단응력 보정 Kα=1인 조건만 다룬다. rd·MSF·Kσ의 자동 상관식은 적용하지 않는다.

기본 amax/g=0.25, σv=180 kPa, σv′=100 kPa, rd=0.9이면 τavg=26.325 kPa, CSR=0.26325다. 기준 CRR=0.18, MSF=Kσ=1일 때 저항/수요=0.68376이다. 화면은 이 조건의 대소 관계를 설명하고 현장의 액상화 여부·확률 또는 안전 판정으로 확대하지 않는다. u0=80 kPa는 지진 전 응력차이며 지진 중 과잉수압 예측이 아니다.

σv′≤0, σv′>σv, rd≤0 또는 rd>1 등 불가능한 조합은 오류로 반환한다. amax=0이면 CSR=0, 저항/수요는 `null`이며 화면에 ‘비교 없음’으로 표시한다. 임의의 무한 안전율을 반환하지 않는다. 화면 슬라이더 범위는 비교 편의 범위이며 독립적으로 지정한 계수 조합의 현장 적용성을 보증하지 않는다.

## 검증

`tests/dynamics.test.mjs`의 28개 검증은 다음을 포함한다.

- SI 단위 손계산, Vs²·ρ·H의 비례 관계, 밀도 변화와 주기의 독립성.
- 모드의 지표·기저 경계, 계산 진동수와 독립 유한차분 곡률의 전단파 방정식 일치.
- γ=0 및 γ=γr, %→소수 변환, 단조 강성저하, 모형 점근값, 유한차분 접선강성 검증.
- CSR 손계산, 가속도·rd·유효응력 비례, 전응력·유효응력 동시 배율 불변성, 보정계수의 적용 방향.
- 0 수요, 0 저항, 같은 저항·수요, 초기 응력경계, 비유한·문자열·오버플로·언더플로 입력 거부.
- 3개 질문의 현재/기준 SVG 유한성, 주 입력 3~5개, 비활성 입력 오류 격리, UI 범위 끝점 렌더링.

화면 변경 시에는 질문 전환, 현재/기준 그림, 비활성 입력 격리, 불가능한 응력 입력의 오류·복구, 가속도 0의 비교 표시와 좁은 화면을 별도로 확인한다.

## 남은 분야

지반 동적 시험자료·감쇠곡선, 반복전단 이력, 여러 층의 선형/등가선형/비선형 부지응답, 입력 시간이력·응답스펙트럼, 유한 기저 임피던스와 증폭, 지반–구조물 상호작용은 별도 구현 대상이다. 액상화에서는 토질의 취약성, SPT/CPT/Vs 기반 저항 평가와 각 보정·적용범위, 지진위험, 과잉수압, 잔류강도, 액상화 후 침하·측방유동을 남겨둔다. 이 입문 묶음으로 그 분야들이 완료된 것처럼 표시하지 않는다.
