# 비배수 점토의 지표 정사각형 지지력

2026-09-22. `bearing-conditions`의 세 번째 질문 `undrained`에 통합한다. 새 메뉴를 추가하지 않는다.

## 제공 질문과 범위

같은 비배수강도 su에서 정사각형 기초를 넓히면 단위면적당 극한저항과 기초 전체 저항이 어떻게 달라지는가? su·한 변 B·전체 전달 하중 W를 함께 조작한다.

균질·포화·등방 점토, 단기 비배수 일반전단, 수평 지표·저면, 중심 수직하중, 지표 정사각형으로 한정한다. L=B, Df=0이며 외부 상재와 지표 위 담수는 없다. 지하수위는 지표이고 기저의 게이지 수압은 0이다. 비배수 과잉수압을 별도로 예측하거나 작용압력에서 다시 빼지 않는다. W는 기초 자중을 포함하여 기초 저면으로 전달되는 전체 하중이며, 자중을 자동 가산하지 않는다.

배수 c′·φ′를 0으로 바꾸어 비배수강도를 흉내 내지 않는다. 기존 배수 입력의 L·Df·c′·φ′·수위·편심·이론 체계는 이 질문에서 비활성이고 검증하지 않는다. su도 배수 질문의 계산과 검증을 방해하지 않는다. B와 W만 질문 사이에서 공유한다. 각 질문의 가정을 기본 화면에 표시한다.

## 출처와 식

직접 원출처: [FHWA NHI-06-089, Soils and Foundations Volume II (2006)](https://www.fhwa.dot.gov/engineering/geotech/pubs/nhi06089.pdf).

- §8.4.2, Eqs.(8-1)~(8-5), pp.8-18~8-19: φ=0에서 Nc=π+2, Nq=1, Nγ=0.
- §8.4.2.1 p.8-22: φ=0의 비배수 하중 조건과 폭·자중 기여항의 관계.
- §8.4.3.1, Table 8-4 p.8-27: 같은 계수 체계의 φ=0 형상계수 sc=1+B/(5L). 정사각형에서는 1.2.

`qnet,u=qult=su(π+2)1.2`, `Qult=qult B²`, `q=W/B²`.

근입 상재압 q₀=0이므로 총·순 극한압력이 같다. 자중 항이 0인 이유는 Nγ=0이지 실제 흙의 단위중량이 0이기 때문이 아니다. Nc를 5.14로 먼저 반올림하지 않는다. 형상계수는 다른 저자의 1.3이나 2D 기구로부터 임의로 구한 값과 혼합하지 않는다. 원문은 로컬 `work/undrained-bearing-review/fhwa.txt`에서 식과 표를 확인했으며, 공식 FHWA 검색 결과와 원 PDF를 대조했다.

## 그림

한 SVG에 왼쪽의 별도 φu=0 Prandtl형 2D 기구와 오른쪽의 **정사각형 계산 결과**를 구별해 표시한다. 기존 `BearingGeometry.prandtl({width,phi:0})`를 재사용한다. 중앙·수동 쐐기각 45°, 방사 전단부 경계는 일정 반지름 원호다. x·y는 같은 물리 축척이다. 기구의 근거는 [University of Newcastle, §5.3](https://newcastle.pressbooks.pub/fundamentals-of-foundation-engineering/chapter/5-3-some-fundamentals-of-the-bearing-capacity-of-shallow-foundations/)와 기존 `docs/bearing-geometry-notes.md`를 따른다.

이 기구는 무중량 2D 띠기초의 별도 해석 그림이다. 정사각형의 실제 3D 파괴면, 변형량 또는 하중 증가에 따른 파괴 진행을 의미하지 않는다. su·W를 바꾸어 기구가 발달하는 것처럼 꾸미지 않는다. 오른쪽은 W 고정의 q=W/B² 곡선과 일정한 qnet,u를 동일 압력축에 표시한다. 비교를 켜면 같은 축에서 저장한 조건을 함께 그린다. 총저항은 결과 카드로 압력과 다른 단위(kN)임을 표시한다.

## API와 검증

`UndrainedBearing.capacity({width=3,totalLoad=1200,su=50})`.

길이 m, 힘 kN, 강도·압력 kPa. width>0, su≥0, W≥0인 유한 숫자만 받는다. 음수·문자열·null·넘침은 실패한다. 명시한 비정사각형/근입, φ′·c′·수위·편심 동시 입력은 지원하지 않으므로 실패한다. descriptor는 활성값 세 개만 전달한다.

기본 예: B=3 m, W=1200 kN, su=50 kPa → A=9 m², q=133.3333 kPa, qnet,u=308.49556 kPa, Qult=2776.4600 kN. 출판된 반올림 Nc=5.14로 손계산하면 308.4 kPa다.

테스트는 독립 손계산, 폭 두 배의 압력 불변·총저항 네 배·요구압력 1/4, 강도와 하중의 분리, 총/순 일치, 81개 UI 조합에서 힘/압력 일치, 0강도·무하중·극한 도달, 범위 오류, 질문 전환 시 비활성 오류 격리, 2D 기구의 원호와 45° 기하를 확인한다.

독립 검증 결과: 새 모형 테스트 10/10, 전체 descriptor 계약 테스트 3/3 통과. 별도 렌더 harness에서 390·768·1440 px × 8조건(비배수 기본/폭·하중·su 경계/폭 2배/기존 배수 두 질문), 총 24조건의 페이지 넘침·비유한 SVG 값·SVG 텍스트 잘림·입력 숫자와 슬라이더 불일치·스크립트 예외가 없었다. 모바일·데스크톱 기본 그림도 직접 확인했다. 이는 명시한 검증 사례의 결과이며 실제 학습자 이해·전 조합·현장 설계 적합성 검증을 의미하지 않는다.

su는 시험방향·응력이력·재하속도에 의존한다. 폭만 바꿀 때 su를 고정하는 것은 채택한 모형 안의 비교다. 근입·편심·층상/강도구배·경사하중·국부/관입전단·압밀·침하·기초판 변형 적합·실무 설계 안전율은 제공 범위가 아니다.
