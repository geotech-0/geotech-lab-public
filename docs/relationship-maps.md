# 두 값의 관계

기존 모형의 입력 두 개를 동시에 바꾸어 만든 단면이다. 별도 해석 엔진이나 현장 설계 판단을 추가하지 않는다. 유효응력, 얕은기초 세 질문, 1차압밀에서 ‘두 값의 관계’를 제공한다.

후속 제공판에서는 점착력·인장균열 질문에도 c′×q 관계면을 추가했다. H·φ′·γ를 고정하고 기존 `CohesivePressure.active`의 무인장 접촉 토압 합력(kN/m)을 그대로 계산한다. 합력 0은 이 건조 모형의 접촉압이 없다는 유효한 결과이며 계산 불가 빗금이나 안전 판정과 구별한다. 수압은 이 단면에 포함하지 않는다.

| 화면 | 가로 × 세로 | 색/선택값 | 고정 조건 |
|---|---|---|---|
| 유효응력 | 수위 깊이 × 상재하중 | 같은 관찰점의 σ′ (kPa) | 관찰 깊이·지층·단위중량, 정수압·배수 완료 |
| 접지압, Q 입력 | B × Q | q (kPa) | 정사각형·지표기초 |
| 접지압, q 입력 | B × q | Q (kN) | 같은 형상, 선택 하중 방식 |
| 침하 | B × Q 또는 q | 중심점 탄성침하 (mm) | E·ν·강도정수, 유연 균일 재하 |
| 지지력 | B × φ′ | qu (kPa) | c′·γ, 같은 계수 체계 |
| 압밀시간 | k × 실제 H | t90 (일) | mv·배수방식·γw·Δσ |

21×21 격자값은 `Mechanics`와 `Consolidation`의 기존 검증 함수를 그대로 호출한다. 선택점은 보간값 대신 같은 계산기를 다시 호출한다. 실제 층두께 H를 배수거리 Hdr로 몰래 바꾸지 않는다. 침하식에는 m→mm의 ×1000, 압밀시간에는 초→일의 ÷86400을 표시한다. k 축과 압밀시간 색은 로그 눈금이다. 끝점에서 부동소수 반올림이 범위 오류를 만들지 않도록 원래 경계값을 사용한다.

모형의 지지력 이상에서 탄성침하는 빗금으로 표시하고 적용을 막는다. 무재하에서는 실재 t90을 표시하지 않는다. 다른 고정 조건이 잘못됐을 때 그럴듯한 색을 채우지 않는다. 빗금은 계산범위 표시이며 설계 적합 판정이 아니다.

열었을 때의 입력을 점선 원, 선택점을 검정 점으로 표시한다. 이는 본 화면의 저장 기준과 별개이며, 다른 물성을 가진 기준을 현재 물성의 관계면 위에 잘못 겹치지 않는다. 고정한 물성·단위는 대화상자에서 펼쳐 확인한다.

그림 선택 또는 숫자/슬라이더 조작은 본 화면을 바꾸지 않는다. ‘이 조건 적용’에서 두 입력을 한 번에 바꾸고 저장한다. 한 번의 되돌리기로 두 값 모두 복구한다. 취소/Escape는 무변경이고 포커스는 열기 버튼으로 돌아간다. 그림을 클릭하지 않아도 숫자·키보드로 모든 점을 선택할 수 있다.

근거식은 기존 `src/mechanics.mjs`, `docs/consolidation.md` 및 각 본 화면 출처를 따른다. 새 상관식은 추가하지 않는다. `tests/relationship-maps.test.mjs`의 16개는 손계산, 기하/하중 비례, 두 층, 배수거리 제곱, 단위/로그 끝점, 범위 밖 차단을 확인한다. 화면 변경 시에는 1440/390 폭에서 적용·취소·되돌리기·입력방식·모드 격리를 별도로 확인한다.
