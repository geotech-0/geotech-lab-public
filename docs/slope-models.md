# 사면의 강도·수압과 지정 활동면

`SlopeModels`와 `SlopeLabs`는 사면의 세 질문을 제공한다. 원호 활동면 탐색·분할법·현장 설계 적합 판정은 별도의 미구현 범위다.

## 무한사면

수직 깊이 z, 사면각 β, 포화 수직두께 hw, 사면에 평행한 침투를 가정한다.

```
σv = q + γmoist(z−hw) + γsat hw
σn = σv cos²β
u = γw hw cos²β
τ = σv sinβ cosβ
R = c′ + (σn−u)tanφ′
F = R/τ
```

수압은 수직 정수압 γw·hw가 아니다. c′=0, 건조일 때 tanφ′/tanβ, 완전 포화 평행 침투일 때 (γsat−γw)/γsat·tanφ′/tanβ가 된다. 깊이와 경사, 물성을 함께 바꿔 점착력과 마찰력의 상대 기여를 확인한다. 그림은 같은 축척으로 그린 평행면이며 유한 사면의 실제 파괴면으로 표현하지 않는다.

## 약층 후보면 — D07

지정한 모층 후보면과 약층 후보면의 깊이·마찰각을 각각 위 식에 대입한다. 두 면의 점착력과 총단위중량은 공통이며 수면은 지표와 평행하다. 더 작은 F를 선택하지만 이것을 전체 지반의 임계 활동면 자동 탐색이라고 부르지 않는다. 얕은 약층에서 큰 점착력 기여 때문에 모층 후보가 지배하다가, 약층을 깊게 옮기면 약층 후보가 지배하는 예제를 검증했다. 실제 유한 약층의 두께·연속성 및 비원호 최적화는 남은 범위다.

## 외부 수위저하와 내부 수압 — D05

좌표 (0,0), (L,Ltanβ), (L,Ltanα)의 단일 직선 쐐기를 사용한다. 0<α<β이며 뒤쪽 수직면은 건조한 열린 경계다. 초기 수위는 활동면 뒤끝보다 낮고, 최종 수위는 초기보다 높을 수 없다. 총중량 W는 모든 수압 상태에서 일정하게 유지하여 두 물 하중의 효과를 분리한다.

```
W = γ L²(tanβ−tanα)/2
Fext = γw hext²/(2sinβ)
U = γw hint²/(2sinα)
N′ = Wcosα + Fext cos(β−α) − U
T = Wsinα − Fext sin(β−α)
R = c′ L/cosα + N′tanφ′
```

초기에는 hext=hint=h₀, 느린 저하 후에는 hext=hint=h₁, 수압이 남는 비교에서는 hext=h₁, hint=h₀로 지정한다. 시간별 수압 소산·비배수강도 변화·실제 급속수위저하 절차를 해석한 결과는 아니다. N′<0 또는 T≤0에서는 이 F를 표시하지 않는다. 지정한 한 면의 힘 평형이며 강체 쐐기의 회전/모멘트 평형이나 전역 안정해를 주장하지 않는다.

## 근거와 검증

- [USACE EM 1110-2-1902 (2003)](https://faculty.washington.edu/kramer/522/ArmySlopeStabilityManual.pdf), Appendix C 식 C-22~C-29, Appendix E 식 E-13: 무한사면 응력 및 평행침투 조건. PDF 83~85·137쪽을 확인했다. 점착력과 연직 상재는 해당 힘 분해에 Mohr–Coulomb 저항과 하중을 더한 명시적 확장이다.
- 위 문헌 Appendix G 및 [USBR Design Standards 13, Chapter 4](https://www.usbr.gov/tsc/techreferences/designstandards-datacollectionguides/finalds-pdfs/DS13-4.pdf): 급속 수위저하에서 외부 물의 지지 효과와 내부 수압·강도 조건을 구별하는 배경. 화면의 단일 쐐기는 이 문헌의 전체 절차가 아닌 직접 유도한 제한 모형이다.

`tests/slope-models.test.mjs`는 독립 힘 분해, 건조/포화 극한, 깊이 배율, 지정 후보면의 지배 전환, 수압 적분, 세 수압 상태와 일치 수위, 정수압에서의 Archimedes 부력 회복 및 잘못된 입력을 검증한다. 화면의 저항비를 설계기준 안전율의 합격/불합격으로 색칠하지 않는다.
