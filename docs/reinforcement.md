# 보강재의 인발·인장 저항

`reinforcement`는 단위 폭 1 m의 동일 단기 비교조건에서 정착길이·유효수직응력·지정 인발계수·지정 인장저항을 바꾼다. 여러 보강층이나 보강토벽 전체의 설계가 아닌 두 저항모드의 기본 비교다.

[FHWA-HIF-24-002 (2023), Chapter 3, Eq.(2), pp.55–56](https://www.fhwa.dot.gov/engineering/geotech/pubs/hif24002.pdf)의 `Pr=F*σ′vLeC`를 사용한다. C=2의 양면 저항, 균일 σ′v(kPa), Le(m)이면 Pr의 단위는 kN/m이다. F*는 시험·흙과 보강재의 상호작용에 근거해 지정하며 자동으로 tanφ와 동일시하지 않는다. 이 판본의 식에는 별도 α가 없으므로 이전 판본과 섞지 않는다.

현재 비교저항 R=min(Pr,T), 두 저항이 같아지는 길이는 T/(2F*σ′v)다. 2F*σ′v=0이면 전환길이는 정의하지 않고 인발저항을 0으로 표시한다. 기본 Le=2m, σ′v=50kPa, F*=0.5, T=80kN/m에서 Pr=100kN/m, R=80kN/m, 전환길이1.6m다.

Le는 지정 활동면 뒤의 저항영역 길이다. 전체 보강재 길이를 자동으로 사용하는 것이 아니다. 크리프·내구성·시공손상·연결부·하중계수·저항계수·외적/복합/전체안정·변형을 제외한다. 보강재의 장기설계강도나 안전율로 R을 제시하지 않는다.

6개 모델 검증: 독립 단위 손계산, 길이·응력·계수 비례, 인장저항에 의한 제한, 지배 전환, 무구속·영저항, 부적합 값 처리. 실제 표시·입력은 공통 브라우저 검사에서 확인한다.
