# 원호 활동면에서 일반 절편법과 간편 Bishop법 비교

## 범위와 좌표

학습용 균질 지반, 일정 단위중량 γ, 유효강도 c′·φ′, 단위 폭 1 m. 지표는 사면 선단 (0,0), 정상 (H/tanβ,H)을 잇는 직선과 그 뒤의 수평면으로 구성한다. 활동 원호는 선단과 정상 뒤 진입점 (xₑ,H)을 통과한다.

- xₑ = H/tanβ + aH; a는 정상 뒤 거리/H.
- y꜀ = kH, k > 1; x꜀ = (xₑ²+H²−2y꜀H)/(2xₑ); R = √(x꜀²+y꜀²).
- 활동면은 아래쪽 원호 y = y꜀−√(R²−(x−x꜀)²).

지표 꺾임에 반드시 절편 경계를 배치한다. 요청한 전체 절편 수는 유지하며, 꺾임 양쪽에 길이 비율로 배분한다. 절편 면적은 원호 적분의 해석식으로 구하고 W = γA로 계산한다. 절편저면 경사 α는 절편 중앙의 접선 경사, ℓ = b/cosα는 그 접선에 대한 저면 길이 근사다. 따라서 면적 적분은 정확하지만 안전율은 절편 수에 따른 수치 근사를 포함한다.

## 수압 모델

모든 절편에서 u = rᵤW/b를 지정한다. 따라서 ub = rᵤW이며, rᵤ는 이 모델에서 절편 평균의 연직 토피응력에 대한 간극수압비다. 수위 위치·등수두선·침투 유동을 풀어서 얻은 결과가 아니다. 같은 γ를 유지한 상태에서 rᵤ만 바꾸므로 수위 변화에 따른 포화 단위중량 변화도 자동으로 반영하지 않는다.

상재하중, 다층·비균질 지반, 외부 저수위 지지력, 인장균열 수압, 급속 수위 저하, 수평 지진력, 보강재는 포함하지 않는다. 무한사면·약층·수위 저하 질문과 입력을 섞지 않는다.

## 일반 절편법의 수압 처리

USACE EM 1110-2-1902 Appendix C, 인쇄 쪽 C-13~C-15, 식 C-12/C-14를 따른다.

- N′ᵢ = (Wᵢ−uᵢbᵢ)cosαᵢ.
- Fₒ = Σ[c′ℓᵢ+N′ᵢtanφ′] / ΣWᵢsinαᵢ.

물속에서 단순히 N′ = Wcosα−uℓ로 계산하는 고전식(C-13)과 구분한다. USACE는 그 식이 지나치게 작은 안전율과 음수 유효 법선력을 만들 수 있어 사용하지 말 것을 명시한다. UI 명칭은 '일반 절편법 · USACE 수압 처리'로 표현하며 모든 Fellenius 구현이 이 식이라고 설명하지 않는다.

일반 절편법은 전체 활동 토체의 모멘트 평형을 적용하고 절편 간 힘을 무시한다. 개별 절편의 수직 힘 평형이나 전체 수평·수직 힘 평형까지 만족한다고 설명하지 않는다.

## 간편 Bishop법

같은 활동 원호, 면적·강도·수압·절편 수를 사용한다. USACE Appendix F, 인쇄 쪽 F-6~F-7, 식 F-4~F-6의 상재하중 P = 0 경우를 적용한다.

- mαᵢ = cosαᵢ + sinαᵢtanφ′/F.
- F = Σ{[c′bᵢ+(Wᵢ−uᵢbᵢ)tanφ′]/mαᵢ} / ΣWᵢsinαᵢ.
- N′ᵢ = [Wᵢ−uᵢbᵢ−c′bᵢtanαᵢ/F]/mαᵢ.

각 절편 수직 힘 평형과 전체 모멘트 평형을 적용한다. 절편 간 전단력은 무시하며 전체 수평 힘 평형까지 만족하는 완전 평형법은 아니다. 일반 절편법과의 차이는 정확도 보증이나 보정계수가 아니라 평형 가정 차이를 나타낸다.

고정점 반복 대신 Φ(F) = Σ Aᵢ/(Fcosαᵢ+sinαᵢtanφ′)−ΣWᵢsinαᵢ = 0, Aᵢ = c′bᵢ+(Wᵢ−uᵢbᵢ)tanφ′를 양의 mα 구간에서 브래킷 이분법으로 푼다. Aᵢ > 0이면 해당 구간에서 Φ가 단조 감소하므로 다른 특이점 가지로 수렴하는 문제를 피한다. 최대 120회, F 구간 폭 상대 10⁻¹², 최종 모멘트식 상대 잔차 10⁻⁹ 이하를 요구한다.

φ′ = 0의 식은 F = Σc′ℓ/ΣWsinα로 직접 계산한다. c′ = φ′ = 0 또는 c′ = 0·rᵤ = 1의 무저항 극한은 F = 0이다. 이때 1/F가 있는 Bishop 반복식은 정의되지 않으므로 수렴 잔차·mα·법선력 분배를 제공하지 않는다. 이를 수렴한 평형해로 표시하지 않는다.

## 유효 법선력과 적용 한계

수치적으로 식이 수렴하더라도 어느 절편이 음수 N′를 가지면 해당 Bishop 안전율은 제시하지 않는다. N′를 0으로 잘라서 다른 물리 모델로 바꾸지 않는다. USACE C-34~C-38은 인장력과 부적절한 유효 법선력 상태를 별도 처리하도록 설명한다.

점착력이 있고 끝단 토체가 얇은 경우, 특히 절편 수 증가 시, 음수 N′가 드러날 수 있다. 절편 수를 줄이는 것은 그 상태의 물리적 해결책이 아니다. 인장균열·균열수압 및 더 일반적인 활동면 처리를 포함하는 별도 모델이 필요하다. 현재 UI는 원호 형상과 유효한 일반 절편법 값은 유지하고 Bishop 결과가 지원되지 않는 이유를 보여 준다.

기본값은 c′ = 0의 사질토로 설정하여 수압비·절편 수·형상 변화가 넓은 범위에서 연속적으로 비교되게 했다. 점착력 입력은 열려 있지만 모델 한계를 숨기지 않는다.

## 제한된 원호 후보 탐색

현재 높이·경사·강도·γ·rᵤ·절편 수에서 a = 0.15~1.5, k = 1.05~2.5를 각각 13개 등간격으로 지정한 169개 원호만 평가한다. 유효한 Bishop 후보 중 최소값을 선택하고, 일반 절편법도 그 **같은 원호**에서 제시한다. 각 방법별로 따로 최솟값을 골라 서로 비교하지 않는다.

탐색 범위·평가 수·지원되지 않는 후보 수·범위 경계에서의 최소 여부를 반환한다. 선단을 통과하지 않는 원호, 비원호, 범위 사이의 연속 원호와 다른 파괴 모드는 탐색하지 않는다. 따라서 전역 최소 안전율이나 설계 검토의 완료가 아니다. F = 1은 이 모델의 저항과 활동이 같은 값이며 설계 합격 기준이 아니다.
