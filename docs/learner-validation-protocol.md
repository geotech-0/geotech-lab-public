# 15분 복습 사용성 검증 진행안

**상태: 실행 준비 · 실제 학습자 검증 미실시.** `src/learning-library.js`의 ‘내 학습 → 짧은 복습’에 있는 6개 분야·각 3단계를 그대로 사용한다. 자동 테스트의 입력·저장·계산 통과와, 사람이 내용을 이해하고 다시 설명하는 것은 따로 기록한다.

## 한 회차 진행

대상은 토질·기초공학을 배웠지만 최근 사용하지 않은 사람이다. 첫 소규모 확인은 3~5명으로 시작할 수 있으며 통계적 효과를 입증하는 연구로 해석하지 않는다. 한 참가자가 **한 분야의 3단계**를 15분 동안 수행한다. 6분야 전체는 여러 참가자·회차에 나누어 다룬다.

- **0~1분:** 참가자가 분야를 고르고 익숙함을 1~5점으로 기록한다. 기존 개인 자료와 섞이지 않는 시험용 브라우저를 사용하거나 입력을 먼저 파일로 보관한다. 관찰자는 조작법을 미리 설명하지 않는다.
- **1~13분:** 단계당 최대 4분. `예측 한 문장 → 값 2개를 독립/동시에 조작 → 결과·대입식 확인 → 자기 설명` 순서다. 풀이 설명은 참가자가 찾거나 요청할 때만 제공하고 도움 여부를 기록한다.
- **13~15분:** 바꾼 입력을 ‘내 예제’에 이름으로 보관하고 미리보기로 다시 연다. 무엇을 기억하게 되었는지, 아직 헷갈리는 점 한 가지를 말한다. 이전 예제를 불러와도 현재/기준/질문을 구별할 수 있는지 본다.

예측이 틀려도 과제 실패로 바로 처리하지 않는다. 조작·그림·설명을 통해 이유를 수정하는지가 핵심이다. ‘스스로 확인’ 체크는 참가자의 자기 기록이며 자동 채점 또는 이해도 인증이 아니다.

## 분야별 3단계 과제와 관찰자의 확인점

| 분야 | 1단계 | 2단계 | 3단계 | 자기 설명에서 확인할 핵심 |
|---|---|---|---|---|
| 흙의 성질 | **입도와 소성**: LL을 고정해 PL 변경, 이어 PL을 고정해 LL 변경. 분류와 소성도표 이동을 예상 | **물과 간극**: e 고정, 함수비를 올려 포화도·단위중량 비교. 불가능한 상태도 한 번 확인 | **같은 간극비의 다른 의미**: e 고정, emin·emax를 변경 | PI는 LL−PL, 전체 USCS에는 입도도 필요. 같은 e라도 Dr이 같지 않음. Sr>100%는 다른 실제 상태로 자동 보정하지 않음 |
| 물과 응력 | **수위와 상재**: 관찰 깊이 고정, 수위만 상승·하중만 추가·함께 변경을 비교 | **같은 수두차의 다른 유량**: Δh와 L을 같은 배율로 변경해 같은 i와 Q 만들기 | **면적과 영향 깊이**: Q 또는 q 고정 조건을 확인하고 폭·깊이를 변경 | σ′=σ−u. 배수 후 하중 증가와 재하 직후 수압을 구별. Q=kAΔh/L, Q/q 고정 의미를 말할 수 있음 |
| 변형과 강도 | **하중 이력**: 최종응력을 선행압밀압력 아래·위로 이동 | **배수 거리와 시간**: 한면↔양면 및 H를 바꿔 같은 압밀도 시간 비교 | **강도와 응력상태**: 구속압·편차응력을 먼저 바꾸고 φ를 변경 | 크기와 속도를 구별. Hdr½→시간¼, 최종침하와 별개. 파괴포락선은 강도조건이며 파괴 후 변형 곡선이 아님 |
| 토압·사면 | **주동·정지·수동**: 같은 지반에서 벽 상태를 바꾸고 필요한 상대변위 설명 | **점착력과 비접촉**: c′와 q를 변경해 비접촉 깊이 줄이기 | **같은 원호의 두 해석**: 원호 고정 후 ru·강도 변경, 이어 후보 탐색 | 음의 이론 토압과 실제 접촉압 0을 구별. ru는 수위 위치가 아님. 두 해석은 같은 원호를 비교하고 후보 최소는 전역 최소가 아님 |
| 기초와 말뚝 | **기초 폭과 고정 하중**: Q 고정과 q 고정에서 폭을 각각 2배로 변경 | **응력 분포와 층별 압축**: 한 층 M만 2배로 변경하고 층두께도 변경 | **저항의 동원 순서**: 머리 하중·주면/선단 동원변위를 변경 | Q 고정이면 q¼, q 고정이면 Q4배. M과 E 및 지정층 압축과 총침하를 구별. 최대 저항과 현재 동원저항은 다름 |
| 조사·개량·판단 | **SPT 보정의 순서**: 측정 N에서 ER 변경, N60 입력 모드로 이동 | **같은 콘 저항의 강도 범위**: u2 보정 및 Nkt 범위를 변경 | **배수 촉진과 교란**: 드레인 간격과 교란 유무를 변경 | N/N60/(N1)60·qc/qt/qnet의 뜻을 구별하고 중복 보정하지 않음. 상관식 계수 범위는 신뢰구간이 아님. 압밀 촉진을 최종침하/강도 확정으로 읽지 않음 |

세 단계의 실제 버튼명·활성 질문은 `LearningReviewRoutes`와 대조한다. 빌드 변경으로 버튼이나 질문이 바뀌면 진행안을 먼저 수정하고, 존재하지 않는 메뉴를 참가자에게 찾게 하지 않는다. 침강 새 질문은 기존 3단계 경로에 자동 포함되지 않으므로 이번 15분 과제의 필수 단계로 끼워 넣지 않는다.

## 매 단계 공통 관찰

- 조작 전에 **무엇을 고정하고 무엇을 바꾸는지** 말하는가?
- 숫자 입력과 슬라이더, 현재와 기준, 표의 결과와 그림을 연결하는가?
- 한 입력만 바꾸어 원인을 분리한 뒤 다중 입력의 관계를 비교하는가?
- 모형 범위를 넘어갔을 때 이전 수치를 정답으로 믿거나, 미계산을 0으로 읽지 않는가?
- 수식·단위·가정을 필요할 때 찾을 수 있는가? 설명을 펼친 뒤 주 실험으로 복귀하는가?
- 모바일에서 값 수정·질문 이동·저장 미리보기를 과도한 왕복 스크롤 없이 수행하는가?

관찰자는 “어떤 값을 고정했나요?”, “지금 그림은 어떤 상태인가요?”처럼 중립적으로 묻는다. 답의 방향을 알려준 경우 도움 1회로 기록한다. 참가자의 발언을 추측으로 보정하지 말고 짧게 그대로 남긴다.

## 자기 설명 기준

각 단계 끝에 “무엇을 바꾸니 무엇이 왜 달라졌고, 이 화면만으로 무엇은 알 수 없나요?”라고 묻는다.

| 점수 | 관찰 기준 |
|---|---|
| 0 | 결과 숫자만 읽거나, 원인·고정 조건을 혼동한 상태가 남음 |
| 1 | 변화 방향 또는 식은 설명하지만 고정 조건·단위·범위 중 중요한 항목이 빠짐 |
| 2 | 고정 조건과 변화 원인을 연결하고, 해당 모형이 계산하지 않는 항목 하나를 구별함 |

속도·점수는 시험 합격이나 실무 역량 판단에 쓰지 않는다. UI가 오해를 줄였는지 확인하는 자료다. 첫 개선 목표는 ‘도움 없이 3단계 진입·조작’, ‘각 단계 설명 2점’, ‘수위·강도·총침하·기준 준수에 관한 중대한 오해 0건’이다. 목표를 못 채우면 해당 화면을 수정하고 같은 질문으로 재확인한다. 소수의 좋은 반응을 전체 사용자 효과로 확대하지 않는다.
